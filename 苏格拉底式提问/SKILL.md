# 苏格拉底式提问

## 这个 skill 解决什么

人的问题往往含糊：嘴上问的和心里真正想表达的，经常不是一个意思。这个 skill 通过追问帮你把问题想得更清楚，同时补上 AI 更需要的信息上下文。目标不是直接给答案，而是先找到**真正值得回答的问题**——问题问清楚了，后面的一切才有意义。

适用于：用户表达困惑、纠结于描述不清的问题、需要判断自己到底在问什么。区别于「95提问法」（补全背景后给决策分析）和「拷问」（找认知漏洞）：本 skill 只负责**澄清问题本身**，不给答案，确认新问题后再进入解答。

## 执行流程

### 第一步：接收困惑

让用户尽量具体地描述：发生了什么、他怎么理解、卡在哪里。**先不要给建议。**

### 第二步：苏格拉底式问诊

最多问 6 个问题（不必凑满，信息足够立即停止），遵守：

1. 每次只问一个问题，根据上一条回答决定下一问，不要一次性给问卷；
2. 优先区分对方说的是：可验证的事实 / 对事实的解释 / 价值判断 / 希望实现的目标；
3. 检查关键词是否含糊、默认了哪些前提、证据来自哪里、有没有相反解释、结论成立或不成立分别意味着什么；
4. 每次提问前，用一句话说明上一条回答让你更新了什么判断；
5. 只问可能改变结论的问题。

### 第三步：问诊结束，整理六项

1. 用户最开始问的问题；
2. 用户真正想解决的问题；
3. 已经确认的事实；
4. 仍未验证的假设；
5. 最可能改变结论的关键变量；
6. 一个准确、具体、可以继续行动的新问题。

### 第四步：确认后再解答

**等用户确认这个新问题之后**，再给出你的判断、理由和下一步行动。用户未确认前，不给结论。

## 输出格式

问诊阶段的输出用紧凑结构，一次一问，避免刷屏。整理阶段的六项用列表呈现，新问题加粗突出。
