# 公司拆解 — 10维商业结构分析

> 用10个维度系统拆解一家公司的商业结构，产出一份结构化分析报告。适用于内容营销选题、投资初筛、竞品研究、行业认知构建。

## Step 0：明确分析对象和目的

拿到用户输入后，确认以下信息。如果用户已经给得足够明确（比如"帮我拆解字节跳动"），不需要追问，按默认目的（内容营销选题）直接开始：

1. **公司名称**：具体公司名（中文名 + 英文名，如有）
2. **分析目的**（可选，影响侧重点）：

| 目的 | 侧重 |
|------|------|
| 内容营销选题（默认） | 商业模式的可讲性、用户画像的共鸣度、增长故事的传播性 |
| 投资/商业评估 | 资产模式的轻重、防御机制的厚度、增长天花板 |
| 竞品研究 | 微笑曲线定位差异、商业模式对比、竞争优势来源 |
| 行业认知 | 市场特点的代表性、该公司作为行业样本的典型性 |

3. **特别关注的维度**（可选）：用户可以指定某几个维度重点展开

---

## Step 1：联网信息收集

**必须联网搜索**，不能仅靠已有知识。公司的最新业务、融资、团队、产品线随时在变，过时信息比没有信息更危险。

### 搜索策略

按以下4组关键词依次搜索，每组至少搜索2-3次，用不同关键词组合：

**第一组：基本面**
- "[公司名] 成立时间 创始人 背景"
- "[公司名] 融资历程 估值"
- "[公司名] 公司简介 业务介绍"

**第二组：业务与产品**
- "[公司名] 主要产品 用户群体"
- "[公司名] 产品线 业务板块"
- "[公司名] 用户画像 目标客户"

**第三组：商业结构**
- "[公司名] 商业模式 盈利模式"
- "[公司名] 营收结构 收入来源"
- "[公司名] 供应链 资产结构"（制造业/硬件公司）
- "[公司名] 竞争对手 行业格局"

**第四组：增长与ESG**
- "[公司名] 增长策略 新业务"
- "[公司名] ESG 社会责任 碳中和"（如相关）
- "[公司名] 行业趋势 市场规模"

### 信息来源优先级

| 信息类型 | 优选来源 |
|---------|---------|
| 公司基本信息 | 天眼查/企查查、官网、招股书/年报 |
| 创始人背景 | 创始人公开演讲、36氪/虎嗅人物专访 |
| 业务/产品信息 | 官网产品页、应用商店、用户评测 |
| 财务/商业数据 | 年报、招股书、36氪/晚点LatePost报道 |
| 竞争格局 | 行业研报（艾瑞/易观）、媒体分析文章 |
| ESG | 官方ESG报告、CSR报告 |

### 信息充分性自检

搜索完成后检查：
- 10个维度中，是否每个都至少有基本事实支撑？
- 关键判断（商业模式分类、微笑曲线定位等）是否有足够证据做出选择？
- 搜不到的维度，标注「信息暂缺」，不编造

---

## Step 2：逐维度分析

按照以下10个维度依次分析。每个维度的分析要求：**先给结论，再给证据和推理**。

### 维度一：基本介绍

输出内容：
- 一句话定义这家公司是什么、做什么
- 所属行业/赛道
- 成立时间、总部所在地
- 当前规模指标（员工数、营收量级、估值/市值，视可获取性）
- 发展阶段判断：初创期 / 成长期 / 成熟期 / 转型期

### 维度二：成立背景

输出内容：
- 成立的时代背景：当时的行业环境、技术趋势、政策环境
- 成立的直接契机：创始人看到了什么机会或痛点
- 早期定位与现在的差异（如有）

### 维度三：创始团队

输出内容：
- 核心创始人/创始团队介绍（教育背景、工作经历、创业经历）
- 创始人的能力特质和基因判断：技术型 / 产品型 / 销售型 / 资源型
- 团队互补性分析（如有多位创始人）
- 当前核心管理团队（如与创始团队有变化）

### 维度四：主要业务与产品

分三个子维度展开：

**4.1 业务板块与产品线**
- 列出所有主要业务板块和对应产品/服务
- 各业务板块的营收占比（如可获取）
- 核心现金牛业务 vs 战略布局业务

**4.2 用户画像**
- 目标用户是谁（To B / To C / To G）
- 用户的核心需求和痛点
- 付费意愿和付费能力

**4.3 微笑曲线定位**

微笑曲线将产业链价值分为三段，判断该公司主要处于哪个位置：

| 位置 | 特征 | 价值来源 | 典型公司 |
|------|------|---------|---------|
| **左端：技术/研发** | 掌握核心技术或知识产权 | 技术壁垒、专利授权 | 高通、ARM、中芯国际 |
| **中间：制造/组装** | 大规模生产制造 | 成本控制、效率优化 | 富士康、立讯精密 |
| **右端：品牌/服务** | 品牌溢价、渠道、售后 | 品牌认知、用户关系 | 苹果、星巴克、海底捞 |

**必须输出**：
- 定位选择：左端 / 中间 / 右端 / 跨段（说明跨哪几段）
- 选择理由：为什么判断在这个位置，用哪些事实支撑
- 趋势判断：是否在向曲线两端移动（中间→两端通常意味着利润率提升）

### 维度五：资产模式

判断该公司的核心资产构成：

| 模式 | 特征 | 优劣势 | 典型公司 |
|------|------|--------|---------|
| **轻资产** | 核心资产是人才、算法、品牌、平台 | 扩展快、边际成本低；但壁垒可能薄 | 字节跳动、美团 |
| **重资产** | 核心资产是厂房、设备、物流网络 | 壁垒高、护城河深；但投入大、转型难 | 京东物流、宁德时代 |
| **无形资产主导** | 核心资产是专利、版权、牌照、数据 | 垄断性强；但依赖法律保护和政策 | 迪士尼、高通 |
| **混合型** | 以上多种组合 | 需说明主次 | 特斯拉（重资产+无形资产） |

**必须输出**：
- 模式判断 + 判断依据
- 该模式对公司扩展性和抗风险能力的影响

### 维度六：商业模式

从**标准化程度**和**规模化能力**两个维度定位：

| 模式 | 标准化 | 规模化 | 特征 | 典型公司 |
|------|--------|--------|------|---------|
| **产品型** | 高 | 高 | 做出标准产品，卖给大量用户 | Apple、微信、ChatGPT |
| **平台型** | 高 | 高 | 连接供需双方，靠交易或流量变现 | 淘宝、美团、滴滴 |
| **订单型** | 中 | 中 | 有一定标准化但每单有定制 | SaaS定制、广告代理 |
| **项目型** | 低 | 低 | 每个项目独立交付，人力密集 | 咨询公司、系统集成商 |

**必须输出**：
- 主商业模式 + 判断依据
- 如果有多条业务线，分别判断（可能不同业务线模式不同）
- 标准化程度和规模化能力的具体表现
- 该模式的天花板在哪里

### 维度七：竞争优势与防御机制

从以下四种防御机制中识别该公司拥有哪些：

| 防御机制 | 定义 | 判断标准 |
|---------|------|---------|
| **品牌知名度** | 用户心智中的占位 | 用户想到品类就想到它？有无品牌溢价？ |
| **规模效应** | 规模越大成本越低 | 是否有明显的成本曲线优势？ |
| **技术壁垒** | 核心技术难以模仿 | 有无关键专利？技术迭代速度？ |
| **网络效应** | 用户越多价值越大 | 用户增长是否带来正反馈循环？ |

**必须输出**：
- 拥有哪些防御机制（可多选），每个给出具体证据
- 防御机制的厚度判断：薄（容易被突破）/ 中（需要大投入才能突破）/ 厚（极难突破）
- 精细化运营手段：从供应链、品牌、营销、产研等维度，描述该公司通过运营效率构建的隐性壁垒

### 维度八：市场特点

判断该公司所在市场的核心驱动力：

| 市场类型 | 特征 | 典型行业 |
|---------|------|---------|
| **价格主导** | 供给弹性低或需求弹性低 | 大宗商品、公用事业 |
| **价差主导** | 原料加工行业，成本波动较大 | 炼油、钢铁、农产品加工 |
| **销量主导** | 需求弹性较高或价格变化不大 | 快消品、互联网流量 |
| **政策主导** | 行业政策周期明显 | 新能源、教育、医药 |

**必须输出**：
- 主导类型判断 + 该公司在此类市场中的策略
- 市场类型是否在发生转变

### 维度九：增长特点和方向

**9.1 提价能力**
- 该公司是否有持续提价能力？依据是什么？
- 提价的来源：品牌溢价 / 产品差异化 / 转换成本高 / 市场垄断

**9.2 二次增长方向**

判断该公司的下一个增长引擎属于哪个方向：

| 增长方向 | 含义 | 判断依据 |
|---------|------|---------|
| **新技术** | 用新技术升级现有业务 | 是否在投入研发新技术？有无技术突破信号？ |
| **新效益** | 提升现有业务的效率 | 是否在做降本增效？运营效率是否还有提升空间？ |
| **新需求** | 开拓新的用户群体 | 是否在进入新的用户市场或地理市场？ |
| **新业务** | 开辟全新业务线 | 是否有新业务孵化？新业务与主业的协同性？ |

**必须输出**：
- 当前增长阶段判断
- 最可能的二次增长方向 + 判断依据
- 增长风险：这个方向的主要不确定性是什么

### 维度十：ESG特征画像

如果该公司有公开的ESG信息，从三个方面分析：
- **E（环境）**：碳排放管理、绿色能源使用、环保投入
- **S（社会）**：员工福利、供应链劳动标准、社区贡献、数据隐私
- **G（治理）**：董事会结构、信息透明度、合规记录

如果公司规模较小或ESG信息极少，简要说明"该公司暂无公开ESG信息"，不硬凑。

## Step 3：一页纸总览

在10维度分析之后，输出一张结构化总览表：

```markdown
## 一页纸总览：[公司名]

| 维度 | 核心判断 |
|------|---------|
| **定位** | [一句话定义] |
| **阶段** | 初创期 / 成长期 / 成熟期 / 转型期 |
| **创始基因** | 技术型 / 产品型 / 销售型 / 资源型 |
| **微笑曲线** | 左端（技术）/ 中间（制造）/ 右端（品牌服务）|
| **资产模式** | 轻资产 / 重资产 / 无形资产 / 混合 |
| **商业模式** | 产品型 / 平台型 / 订单型 / 项目型 |
| **核心防御** | [列出拥有的防御机制] |
| **市场类型** | 价格 / 价差 / 销量 / 政策 主导 |
| **增长方向** | 新技术 / 新效益 / 新需求 / 新业务 |
| **ESG亮点** | [一句话概括，或"暂无公开信息"] |
```

## Step 4：关键洞察

在一页纸总览后，根据分析目的加一段300-500字的关键洞察，回答对应核心问题：

- **内容营销**：这家公司最值得讲的故事是什么？哪个维度最有传播性？
- **投资评估**：核心风险和核心机会分别是什么？
- **竞品研究**：相比我们，它的结构性优势/劣势在哪里？
- **行业认知**：这家公司作为行业样本，揭示了什么行业规律？

## 规则

### 必须做
1. **每个分类判断都给理由**：不能只写"商业模式：产品型"，必须说清楚为什么
2. **区分事实和判断**：事实标注来源，判断标注"判断依据"
3. **搜不到就说搜不到**：标注"信息暂缺"，不编造
4. **结论先行**：每个维度先给判断结论，再展开论证
5. **具体优于概括**：用数字、产品名、具体事件代替空洞描述

### 不要做
1. **不要写成百科词条**：每个维度要有分析判断，不是信息堆砌
2. **不要所有维度平均用力**：信息充足的维度展开写，信息不足的简要标注即可
3. **不要硬套框架**：如果某个分类选项都不完全匹配，说"最接近X，但有以下差异"
4. **不要忽略混合情况**：很多公司是混合型的，如实描述
5. **不要用AI套话**："赋能"、"打造闭环"、"不难发现"、"值得注意的是"——一个都不要出现
6. **不要编造ESG信息**：小公司没有ESG就直说
7. **不要漏掉信息来源**：末尾必须列出主要引用来源
