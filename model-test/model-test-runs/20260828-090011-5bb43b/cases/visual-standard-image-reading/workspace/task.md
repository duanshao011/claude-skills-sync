# 任务

请查看 `input/campaign-board.png`，提取图片中的确定事实。不要读取图片之外的文件来猜答案。

在 `submission/` 生成：

- `answers.json`：包含 campaign_name、launch_date、owner、total_budget、channels、status_counts、largest_budget_channel。
- `observations.md`：说明你从图片中看到的关键信息，区分确定内容与因字号、图例或画面限制而不确定的内容。

金额写数字，不带货币符号。日期使用 `YYYY-MM-DD`。状态数量按绿色、琥珀色、红色分别统计。
