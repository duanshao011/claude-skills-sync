## 二、小红书

### 入口
1. **蒲公英平台（pgy.xiaohongshu.com）**：品牌与博主商业合作的官方平台。品牌侧流程：先到小红书专业号平台完成企业资质认证 → 用专业号信息登录蒲公英 → 找博主、发任务、审内容、看数据、结算。走代理需另在"合作伙伴平台"入驻；找买手带货走电商官网入驻后开通分销。
   来源：https://pgy.xiaohongshu.com/role-introduce?needLogout=needLogout （官方页，浏览器直接打开需登录）
2. **聚光平台（ad.xiaohongshu.com）**：官方一站式广告投放平台（搜索+信息流），用于给合作笔记加热、放大曝光。页面已验证可访问，开户操作需登录后台。

### 授权 / 审核 / 商品链路注意点
- **必须报备**：品牌合作的笔记须经蒲公英报备并添加"商业合作"声明，私下合作（水下笔记）有限流、下架风险；小红书《社区公约》要求创作者"申明利益相关"。该规则的官方页面在登录墙内，第三方口径高度一致，建议以蒲公英后台规则中心为准。
- **站外成交**：2025年5月起"红猫计划"开放笔记下方"广告挂链"，可直跳淘宝天猫店铺/商品，全链路数据在淘宝"种草星河"平台观测；目前面向部分试点/优质品牌开放，非全部品牌可用。来源：https://m.huanqiu.com/article/4Ma7DTDkrcX 、https://static.nfnews.com/content/202505/07/c11266114.html?enterColumnId=5944
- 蒲公英入驻本身免费；有第三方称平台收取约10%服务费——**未获官方页面证实**，以下单结算页为准。

### 确认 vs 受限
- ✅ 可确认：蒲公英是官方撮合/报备平台；品牌侧需企业专业号；聚光为官方投放后台。
- ⚠️ 受账户权限/行业影响：特殊行业需额外行业资质（以专业号/聚光认证页提示为准）；"广告挂链"跳淘宝天猫目前试点开放，能否开通以平台审批为准。

## 三、抖音

### 入口
1. **巨量星图（www.xingtu.cn）**：抖音官方达人营销平台，品牌（客户）侧注册需资质认证、对公验证。帮助中心：https://www.xingtu.cn/help-center/demander/126583
2. **巨量千川 / 小店随心推**：电商投流平台，入口 qianchuan.oceanengine.com 或抖店后台"推广"，用于给合作达人的视频投流。官方协议见：https://school.jinritemai.com/doudian/web/articlev0/aHZCbcQG8ZR8

### 可用的合作模式（官方帮助中心已核实）
- **招募任务-一口价**：批量合作中腰尾达人（1K–500W粉），单次任务**1万元起投**，达人自主折扣报价最低可到一口价2折，平台服务费5%；可一次下单批量合作，支持视频一键推送到千川等平台投放。来源：https://www.xingtu.cn/help-center/demander/126583
- **指派任务**：定向邀约指定达人，一口价结算；下单时可单独增加一笔"素材授权费"（也可免费授权），合并支付。来源：https://www.xingtu.cn/help-center/author/139123
- **素材任务**：达人不出镜发布、仅交付素材+肖像授权书，适合TVC/投放素材，首期限明星或500万粉以上达人。来源：https://www.xingtu.cn/help-center/demander/206682
- **星川任务（千川星选）**：星图与千川联合产品，达人产出的带货素材直接在品牌官方/自运营账号下投放。来源：https://www.xingtu.cn/help-center/author/185745

### 授权 / 审核 / 商品链路注意点（本平台规则最细，重点看）
- **投流授权必须下单时勾选**：发单时启用「视频推送至投放平台」并勾选千川/DOU+/本地推/巨量营销，否则视频无法通过星图推送投流。**默认授权时长30天，上限365天**，到期需重新发起授权。来源：https://www.xingtu.cn/help-center/demander/114316
- 千川仅支持**闭环购物车**组件；推500个账户内免费；推送账户主体不强制与下单主体一致，但账户需完成对应平台资质认证。
- **内容审核**：客户自审模式下，达人上传视频后**3天内未确认即自动通过发布**，务必盯审核；也可选平台代审。招募任务视频发布90天后不能再推送投流。
- **报备合规**：商单须走星图并由达人做商业标识；《互联网广告管理办法》要求广告内容可识别，未标"广告"的商单有市场监管处罚风险（第三方合规分析，供参考）：https://www.byerisk.com/blog/douyin-xingtu-ad-filing-compliance ；星图官方《内容管理规范》：https://www.xingtu.cn/help-center/mcn/136204
- **行业限制**：「三品一械」（药品/医疗器械/保健食品/特殊化妆品等）客户**不可用**招募任务和投稿任务，只能加白合作指派任务。来源：126583 同页。

### 确认 vs 受限
- ✅ 可确认：以上任务模式、起投门槛、服务费、授权时长均出自星图官方帮助中心，2026年8月仍在更新。
- ⚠️ 受账户/行业影响：星图客户注册需对公验证；三品一械等行业被排除在部分任务外；千川投放需有抖音小店（或按平台规则开通）。

## 四、B站

### 入口
1. **花火平台（huahuo.bilibili.com）**：B站官方UP主商业合作平台。品牌主流程：注册（可用B站账号或手机号，蓝V账号可授权继承认证信息加速）→ 企业资质+行业资质认证 → 解锁UP主广场 → 询单私信 → 线上签合同 → 审核UP主脚本/样片 → 发布 → 平台结算。来源（官方入驻指南）：https://www.bilibili.com/blackboard/activity-KdgoH1DKVh.html ；平台介绍：https://e.bilibili.com/observe/observe_40.html
2. **投流工具**：花火合作内容可叠加**商业起飞**（内容加热）、**邀约广告**（视频框内/框下转化位）、**联合投稿**（品牌官号与UP主联合发布）。
3. **带货**：**悬赏计划**是B站官方带货服务，UP主可通过评论区、橱窗、直播等位带货拿分成。来源（官方UP主营销地图）：https://www.bilibili.com/blackboard/activity-BPiQy33YHl.html

### 授权 / 审核 / 商品链路注意点
- UP主侧入驻门槛（决定你能选到谁）：实名认证+18岁+**粉丝≥1万**+电磁力信用分≥60；未达标但已有商机的可申请特殊入驻。来源：https://m.bilibili.com/opus/672301384317534227 、https://www.bilibili.com/blackboard/activity-C1aZCOqlAI.html
- **影响**：1万粉门槛意味着B站腰尾部达人供给比抖音（招募任务1K粉起）明显少，小UP主若未入驻花火，只能走特殊入驻流程，周期不可控。
- 合同、内容审核（脚本/样片）均在花火线上流程内完成，未经花火的商单同样有违规推广风险。
- 花火品牌侧入驻免费；**当前服务费率未获官方页面证实**（上线初期曾限时免收），以下单页为准。

### 确认 vs 受限
- ✅ 可确认：花火是官方平台、品牌侧流程、UP主入驻门槛、起飞/邀约/联合投稿/悬赏计划均为官方页面或官方公告。
- ⚠️ 受限：部分官方页（入驻指南、UP主营销地图）需浏览器正常渲染/登录才可见全文；行业资质按行业提交，金融、医疗等特行业审核更严。

## 五、给中小品牌团队的选择建议

结合你们的情况（月合作10–20位达人、关心曝光/主页/进店/成交、无法务、预算有限、不买系统）：

1. **主力放抖音，首选"招募任务"**。1万元起投、批量合作中小达人、折扣价、下单即完成报备和授权推送，是三个平台里对中小预算最友好的标准品。有抖音小店就同步勾选千川授权（注意默认授权只有30天，投得久的视频要提前续期）。
2. **小红书走"蒲公英报备 + 聚光加热"**。先完成企业专业号认证（这是蒲公英和聚光的共同前提），合作走蒲公英报备避免限流；表现好的笔记用聚光追投。若成交主力在淘宝天猫，尽早申请"广告挂链"试点，打通进店/成交数据。
3. **B站按品类决定，不要当主阵地**。花火流程最完整（合同+样片审核），但达人门槛1万粉、单条内容制作周期长，适合客单价高、决策链长的品类做深度内容；纯曝光/快转化场景效率不如前两者。
4. **合规底线三件事**（没有法务也能执行）：所有商单一律走官方平台下单报备；要求达人内容带商业标识/"广告"声明；投放授权一律在平台内完成并记录授权到期日。
5. **不要先买系统**。三平台的达人筛选、报备、审核、结算、数据都能在官方后台完成，先用官方功能跑一个完整月度周期，再看是否需要第三方数据工具补充选号。
