# 周复盘质量评分规则

用于自评、复核他人复盘、或用户要求给复盘打分时。5 个维度各 0–2 分，总分 10。逐项核对，每个扣分点都要指出具体条目。

## 1. 证据完备性（0–2）

- 2 分：事实区每条都有可回查的出处（文件名/数据/条目），抽查能对上。
- 1 分：大部分有条目缺出处，或出处笼统（只写"周报"没有定位到条目）。
- 0 分：存在无证据的"完成事项"，或证据与描述对不上。

## 2. 动作/结果区分（0–2）

- 2 分：事实区每条都指向可观察变化（指标变化、产出物、闭环）；纯动作全部进了"未完成"分析。
- 1 分：混入 1–2 条只有动作没有变化的事项。
- 0 分：大量"推进了/跟进中/初步完成"被写成成果。

## 3. 归因质量（0–2）

- 2 分：未完成事项的原因具体（依赖谁、卡在哪一步、优先级冲突），且归因有材料支撑；材料不足处明确写"原因不明，需确认"。
- 1 分：原因笼统（"时间不够""优先级问题"）且无材料支撑。
- 0 分：编造原因，或根本没分析未完成事项。

## 4. 行动可查证性（0–2）

- 2 分：行动 ≤3 条，每条完成信号是具体数字/交付物/对方反馈，下周末可客观判定完成与否。
- 1 分：完成信号模糊（"基本搞定""有明显起色"），或行动超过 3 条。
- 0 分：行动没有完成信号，或行动与判断区的结论脱节（判断指出的问题没有对应行动）。

## 5. 结构与结论（0–2）

- 2 分：结论先行且 ≤3 句、能独立成立；三区无混写；材料不全时标注了"基于不完整材料"。
- 1 分：结论超长或含混，或有少量事实/判断混写。
- 0 分：没有结论区，或大量混写，或用编造内容填补材料缺口。

## 判定

- 9–10：可用，直接交付。
- 7–8：可用，标注薄弱维度提醒用户。
- ≤6：退回重做，指出未通过的具体条目。
