# 周复盘

固定输出顺序：**结论 → 事实 → 判断 → 下周行动**。全程默认中文，结论先行。

## 核心纪律

1. **证据门槛**：每条"完成事项"必须能指向一个材料来源（周报条目、数据截图、文件、笔记原文）。来源直接标注在事实后面，格式如 `（证据：xx周报 8/26 条目）`。材料里找不到的，不写。
2. **动作 ≠ 结果**：只把产生了可观察变化的事写进"完成事项"。判断句式用"X 指标从 A 到 B / X 文件产出 / X 闭环完成"，禁用"推进了""持续跟进""初步完成"这类无结果表述——动作再多，没有变化就归入"未完成"，进判断区分析原因。这样区分是因为复盘的价值在归因，把动作写成结果会让下一周的优先级判断失真。
3. **三区分离**：事实、判断、下周行动各占一节，不混写。事实只描述发生了什么，判断只放归因和评价，行动只放下一步。
4. **只留 3 个行动**：下周行动最多 3 条，每条必须带**完成信号**——一个下周结束时能客观查证的具体状态（数字、交付物、对方反馈）。写不出完成信号的行动删掉。

## 工作流程

1. **清点材料**：列出用户给了哪些材料，各自覆盖本周哪些天/哪些项目。缺口直接告诉用户（如"没有数据结果，本周效果无法判断"）。
2. **收证据**：从材料里逐条提取"做了什么 + 结果是什么 + 出处"。同一件事多个来源冲突时，以带数字/文件的那条为准，冲突本身写进判断。
3. **写判断**：回答三个问题——哪些是真结果？哪些只是动作？没完成的卡在哪（材料缺/依赖他人/优先级/能力）？归因必须有材料支撑，材料不足就写"原因不明，需向用户确认"，不许编。
4. **定行动**：从判断里反推，选出下周影响最大的 3 件事，各配完成信号。

## 输出模板

```
# 周复盘（8/24–8/28）
## 结论
（≤3 句：真结果一句话；最大问题一句话；下周最重要的一件事一句话。材料不全时首句标注"本复盘基于不完整材料"。）
## 事实
- <发生了什么>（证据：<出处>）
## 判断
- 真结果：…
- 只是动作：…
- 未完成：…（原因：…；材料不足以归因时写"原因不明，需确认"）
## 下周行动（≤3 条）
1. <行动> — 完成信号：<下周末可查证的具体状态>
```

## 输入不足时（不能编造）

- 材料完全缺失或明显不够覆盖"一周"：先输出已有材料的清点，列出**具体缺什么**（哪几天、哪类数据），问用户能否补充，**不要基于想象补全完成事项**。宁可交一份只有缺口清单的复盘，也不交一份看起来完整但靠编的复盘。
- 用户表示就用现有材料复盘：正常走流程，但在结论里明确标注"本复盘基于不完整材料"，事实区只写有证据的条目。

## 完成校验（交稿前逐项自查）

1. 事实区每条末尾都有 `（证据：…）`，且证据能在材料中回查到。
2. 全文没有用"推进了/持续跟进/初步完成"等词描述已完成事项——这类事项要么有可观察变化（进事实区），要么没有（进判断区当未完成）。
3. 下周行动 ≤3 条，每条的完成信号是数字/交付物/对方反馈之一，写不出的已删除。
4. 判断区没有引入新事实，事实区没有评价性词汇。

## 详细评分规则

对复盘质量有更高要求（如自评、给用户打分、复核他人复盘）时，读 [references/rubric.md](references/rubric.md)，按 5 个维度逐项核对。日常复盘不需要读。
