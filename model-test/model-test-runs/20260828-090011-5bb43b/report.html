# 加班到十点，肩膀硬得像块板子，我最近就这么对付

说出来有点不好意思，我一个天天对着电脑改方案的人，晚上回家的标配动作是：包一扔，人往沙发上一瘫，然后自己伸手去捏后颈，捏两下，龇牙咧嘴。

不是什么大毛病，就是那种坐了一整天的僵。脖子往后仰一下，咔的一声，肩胛骨附近酸得发紧。推拿也去过，一次一百多，来回路上还得一个多小时，加班到十点的人根本排不进日程。

后来同事看我上班中途老用脖子画圈，随手塞给我一片松间热敷贴，说你贴着试试。

我的用法很简单：到家洗完澡，把它贴在睡衣外面，正好盖住后颈到肩的位置。它是蒸汽热敷的那种，撕开之后慢慢热起来，大概能持续发热30分钟。这30分钟我一般就是窝在沙发上看剧，或者干脆闭着眼躺着，热气敷在僵掉的那块地方，整个肩膀一点点松下来。那半小时基本就是一天里最不紧绷的半小时。

有几个细节提醒一下，都是我自己用过才知道的：

它要贴在衣物外侧，不要直接贴皮肤，热敷贴贴在皮肤上容易低温烫伤，这个别省事。

它是发热让你舒服一点的东西，不是医疗器械，颈椎病什么的它治不了，该看医生还是要看医生。我把它理解成"下班后的热毛巾升级版"——不用我去烧热水拧毛巾，也不用毛巾敷到一半凉了再爬起来去换热水的。

如果你在杭州，可以先不买。杭州有3个线下体验点，在小程序上能查到地址，路过的时候去感受一下热度和蒸汽的感觉，觉得合适再说。

觉得合适的话，可以先拿体验装试试：39元一共7片，正好连续7天，每晚洗完澡贴一片。一周刚好是工作日最熬人的节奏，每天那30分钟能不能让你松下来，自己身体会告诉你。像我现在，包还没放下，先撕一片贴上，已经成了下班仪式感的一部分。

长期伏案的应该都懂那种感觉：白天deadline压着不敢动，晚上肩膀酸得不想动。与其硬扛，不如每天给自己留30分钟热敷的时间，就当是跟自己这副身体和解一下。

## 三、抖音

### 入口
1. **巨量星图（www.xingtu.cn）**：抖音官方达人营销平台，品牌（客户）侧注册需资质认证、对公验证。帮助中心：https://www.xingtu.cn/help-center/demander/126583
2. **巨量千川 / 小店随心推**：电商投流平台，入口 qianchuan.oceanengine.com 或抖店后台"推广"，用于给合作达人的视频投流。官方协议见：https://school.jinritemai.com/doudian/web/articlev0/aHZCbcQG8ZR8

### 可用的合作模式（官方帮助中心已核实）
- **招募任务-一口价**：批量合作中腰尾达人（1K–500W粉），单次任务**1万元起投**，达人自主折扣报价最低可到一口价2折，平台服务费5%；可一次下单批量合作，支持视频一键推送到千川等平台投放。来源：https://www.xingtu.cn/help-center/demander/126583
- **指派任务**：定向邀约指定达人，一口价结算；下单时可单独增加一笔"素材授权费"（也可免费授权），合并支付。来源：https://www.xingtu.cn/help-center/author/139123
- **素材任务**：达人不出镜发布、仅交付素材+肖像授权书，适合TVC/投放素材，首期限明星或500万粉以上达人。来源：https://www.xingtu.cn/help-center/demander/206682
- **星川任务（千川星选）**：星图与千川联合产品，达人产出的带货素材直接在品牌官方/自运营账号下投放。来源：https://www.xingtu.cn/help-center/author/185745

### 授权 / 审核 / 商品链路注意点（本平台规则最细，重点看）
- **投流授权必须下单时勾选**：发单时启用「视频推送至投放平台」并勾选千川/DOU+/本地推/巨量营销，否则视频无法通过星图推送投流。**默认授权时长30天，上限365天**，到期需重新发起授权。来源：https://www.xingtu.cn/help-center/demander/114316
- 千川仅支持**闭环购物车**组件；推500个账户内免费；推送账户主体不强制与下单主体一致，但账户需完成对应平台资质认证。
- **内容审核**：客户自审模式下，达人上传视频后**3天内未确认即自动通过发布**，务必盯审核；也可选平台代审。招募任务视频发布90天后不能再推送投流。
- **报备合规**：商单须走星图并由达人做商业标识；《互联网广告管理办法》要求广告内容可识别，未标"广告"的商单有市场监管处罚风险（第三方合规分析，供参考）：https://www.byerisk.com/blog/douyin-xingtu-ad-filing-compliance ；星图官方《内容管理规范》：https://www.xingtu.cn/help-center/mcn/136204
- **行业限制**：「三品一械」（药品/医疗器械/保健食品/特殊化妆品等）客户**不可用**招募任务和投稿任务，只能加白合作指派任务。来源：126583 同页。

### 确认 vs 受限
- ✅ 可确认：以上任务模式、起投门槛、服务费、授权时长均出自星图官方帮助中心，2026年8月仍在更新。
- ⚠️ 受账户/行业影响：星图客户注册需对公验证；三品一械等行业被排除在部分任务外；千川投放需有抖音小店（或按平台规则开通）。

# 周复盘质量评分规则

用于自评、复核他人复盘、或用户要求给复盘打分时。5 个维度各 0–2 分，总分 10。逐项核对，每个扣分点都要指出具体条目。

## 1. 证据完备性（0–2）

- 2 分：事实区每条都有可回查的出处（文件名/数据/条目），抽查能对上。
- 1 分：大部分有条目缺出处，或出处笼统（只写"周报"没有定位到条目）。
- 0 分：存在无证据的"完成事项"，或证据与描述对不上。

## 2. 动作/结果区分（0–2）

- 2 分：事实区每条都指向可观察变化（指标变化、产出物、闭环）；纯动作全部进了"未完成"分析。
- 1 分：混入 1–2 条只有动作没有变化的事项。
- 0 分：大量"推进了/跟进中/初步完成"被写成成果。

## 3. 归因质量（0–2）

- 2 分：未完成事项的原因具体（依赖谁、卡在哪一步、优先级冲突），且归因有材料支撑；材料不足处明确写"原因不明，需确认"。
- 1 分：原因笼统（"时间不够""优先级问题"）且无材料支撑。
- 0 分：编造原因，或根本没分析未完成事项。

## 4. 行动可查证性（0–2）

- 2 分：行动 ≤3 条，每条完成信号是具体数字/交付物/对方反馈，下周末可客观判定完成与否。
- 1 分：完成信号模糊（"基本搞定""有明显起色"），或行动超过 3 条。
- 0 分：行动没有完成信号，或行动与判断区的结论脱节（判断指出的问题没有对应行动）。

## 5. 结构与结论（0–2）

- 2 分：结论先行且 ≤3 句、能独立成立；三区无混写；材料不全时标注了"基于不完整材料"。
- 1 分：结论超长或含混，或有少量事实/判断混写。
- 0 分：没有结论区，或大量混写，或用编造内容填补材料缺口。

- 7–8：可用，标注薄弱维度提醒用户。

# 周复盘

固定输出顺序：**结论 → 事实 → 判断 → 下周行动**。全程默认中文，结论先行。

## 核心纪律

1. **证据门槛**：每条"完成事项"必须能指向一个材料来源（周报条目、数据截图、文件、笔记原文）。来源直接标注在事实后面，格式如 `（证据：xx周报 8/26 条目）`。材料里找不到的，不写。
2. **动作 ≠ 结果**：只把产生了可观察变化的事写进"完成事项"。判断句式用"X 指标从 A 到 B / X 文件产出 / X 闭环完成"，禁用"推进了""持续跟进""初步完成"这类无结果表述——动作再多，没有变化就归入"未完成"，进判断区分析原因。这样区分是因为复盘的价值在归因，把动作写成结果会让下一周的优先级判断失真。
3. **三区分离**：事实、判断、下周行动各占一节，不混写。事实只描述发生了什么，判断只放归因和评价，行动只放下一步。
4. **只留 3 个行动**：下周行动最多 3 条，每条必须带**完成信号**——一个下周结束时能客观查证的具体状态（数字、交付物、对方反馈）。写不出完成信号的行动删掉。

## 工作流程

1. **清点材料**：列出用户给了哪些材料，各自覆盖本周哪些天/哪些项目。缺口直接告诉用户（如"没有数据结果，本周效果无法判断"）。
2. **收证据**：从材料里逐条提取"做了什么 + 结果是什么 + 出处"。同一件事多个来源冲突时，以带数字/文件的那条为准，冲突本身写进判断。
3. **写判断**：回答三个问题——哪些是真结果？哪些只是动作？没完成的卡在哪（材料缺/依赖他人/优先级/能力）？归因必须有材料支撑，材料不足就写"原因不明，需向用户确认"，不许编。
4. **定行动**：从判断里反推，选出下周影响最大的 3 件事，各配完成信号。
