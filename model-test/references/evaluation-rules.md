# 评审边界

## 自动检查

自动检查只回答两件事：

1. 规定产物是否生成并可读取。
2. 是否存在能用确定答案验证的客观错误。

典型项目包括数据计算、字段覆盖、文件遗漏、链接数量、项目构建、结构语法和图片中的确定事实。

## 用户判断

以下项目不做模型自动质量评分：

- 内容的 AI 味、自然度、节奏和观点价值。
- 调研洞察和决策价值。
- 业务结论是否真正有帮助。
- 需求理解、成品感和省心程度。
- 图片语境理解与前端审美。

用户只需要选择：`直接可用`、`小改可用`、`需要大改`、`不会使用`。备注可选。

## 难度

常规题验证日常胜任力。压力题通过真实材料噪音、冲突信息、较长任务链、更多约束和自我验证要求寻找能力边界。不得使用冷门知识或文字陷阱制造虚假难度。
