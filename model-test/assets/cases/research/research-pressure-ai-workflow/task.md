# 任务

一位没有开发基础的内容营销负责人，正在用 Codex、Claude Code 和第三方模型路由处理项目开发、数据分析、Skill、本地文件、内容营销与调研。请根据截至测试当天的官方资料，形成一份实际选型报告。

## 复杂条件

- 产品和模型能力变化快，旧文章可能已经过期。
- “模型能力”和“Agent工具能力”不能混为一谈。
- 不同产品的Token、费用和套餐口径可能不可直接比较。
- 公开资料可能只描述能力，不保证每个账户或第三方路由可用。

## 交付要求

在 `submission/` 生成：

- `report.md`：比较 Codex 与 Claude Code 在项目文件、工具调用、Skills或类似扩展、非交互运行、费用可见性等方面的实际差异，并给出按任务分工建议。
- `sources.json`：包含调研截止日期和来源数组。每条来源至少记录标题、URL、来源方、发布日期或更新时间、支持的结论。

关键论断必须靠近来源。把内容分成已确认事实、基于资料的推断和仍然未知三类。发现资料冲突时说明采用哪一个及原因，不要悄悄选择。
