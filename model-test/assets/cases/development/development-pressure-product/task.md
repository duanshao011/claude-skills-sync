# 任务

内容团队需要一个不依赖服务器的“一周内容排期器”。负责人只提供了业务目标和品牌资料，没有现成设计稿。请自行完成需求理解、页面设计、功能实现和验证。

## 必须满足

- 交付到 `submission/site/`，直接打开 `index.html` 可用。
- 展示7天排期，每条内容包含日期、平台、主题、负责人和状态。
- 可以按平台和状态筛选。
- 可以新增一条内容并立即显示。
- 刷新页面后新增内容仍然保留。
- 提供清空本地新增内容的方法，但不能误删内置示例。
- 手机宽度下仍然可读和可操作。
- 空筛选结果要有明确提示。
- 视觉要像团队真的愿意每天打开的工作工具，不使用紫色渐变、玻璃拟态或无意义动画。

请使用原生 HTML、CSS 和 JavaScript，不安装依赖。交付前实际检查主要交互。
