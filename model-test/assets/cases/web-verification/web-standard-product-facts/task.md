# 任务

请联网核验 `input/claims.md` 中的4条陈述。只能把能被当前官方资料直接支持的内容标为“确认”。官方资料没有明确说明时标为“无法确认”，不要用搜索摘要或第三方转述补齐。

## 交付要求

在 `submission/` 生成：

- `verdicts.json`：包含 cutoff_date 和 claims 数组。每条记录包含 id、verdict、reason、sources。verdict 只能是 `确认`、`错误`、`部分正确`、`无法确认`。
- `evidence.md`：逐条解释判断，附直接来源链接、页面标题和页面日期或访问日期。

优先查官方产品文档、帮助中心、CLI帮助或官方发布说明。发现能力依赖版本、账户或运行环境时必须写清条件。
