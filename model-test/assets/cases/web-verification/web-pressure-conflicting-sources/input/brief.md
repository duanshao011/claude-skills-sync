# AI工具能力速报待核验项

1. Claude Code 所有模型路由都会返回准确的美元费用。
2. Codex CLI 的 JSON 输出一定包含美元费用字段。
3. Claude Code 的 `--bare` 与 `--safe-mode` 是同一个功能的两个名字。
4. Codex Skills 与 Claude Code Skills 都可以在项目中提供本地工作规则，但界面元数据和自动发现规则完全一致。
5. 非交互Agent运行只要输出了最终文本，就能精确拆分每个工具调用消耗的Token。
6. 通过第三方API把模型接入Claude Code后，Agent工具体验和模型原生产品必然完全相同。
