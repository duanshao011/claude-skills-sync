# 任务

内容团队收到一份“AI工具最新能力速报”，其中混合了旧版本信息、二手报道、模糊措辞和可能正确的新变化。请对 `input/brief.md` 中的6条陈述逐条核验。

## 要求

- 搜索截止到测试当天。
- 优先追到产品官方文档、官方发布说明、官方定价页或官方代码仓库。
- 同一结论出现新旧页面冲突时，比较发布日期、适用版本和页面状态。
- 区分“产品支持”“当前账户可用”“第三方路由兼容”三种不同结论。
- 无法从公开资料确认时直说，不能用模型常识补齐。

在 `submission/` 生成：

- `fact-check.md`：逐条给出确认、错误、部分正确或无法确认，并附证据。
- `source-map.json`：包含截止日期和claims数组，每条记录关联原始来源、发布时间、访问时间、适用范围和冲突来源。
