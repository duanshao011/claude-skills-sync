# 任务

`input/legacy.html` 是一页真实信息齐全但视觉杂乱的活动招募页。请保留 `input/content.md` 中的事实和信息结构，重新制作一个有成品感、可直接展示的单页。

## 设计目标

- 受众是杭州25-35岁的内容创作者。
- 气质克制、城市感、清楚，不做科技发布会风格。
- 不使用AI紫色渐变、玻璃拟态、三张完全相同的功能卡、巨大空洞口号或无意义动效。
- 只使用一个强调色，页面在手机上完整可用。
- 报名按钮、日程折叠和常见问题需要有真实交互。
- 尊重 `prefers-reduced-motion`。

## 交付

将原生 HTML、CSS、JavaScript 放入 `submission/site/`，直接打开 `index.html` 可用。不安装依赖，不从网络加载字体或脚本。交付前实际检查桌面和手机宽度。
