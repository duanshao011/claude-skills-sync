# 任务

`input/broken-skill/` 是一个正在使用但经常跑偏的文件简报 Skill。请先诊断问题，再交付一个修复版本到 `submission/file-brief/`。

## 修复目标

- 只处理“从用户明确指定的本地文件生成简报”，不吸引所有总结或写作任务。
- 不扫描整个电脑，不读取未指定目录。
- 输入为空或文件不支持时给出清楚反馈。
- `SKILL.md` 保持简洁，详细流程放在按需reference中。
- 使用确定性脚本检查输入路径清单，不在脚本中读取文件正文。
- 移除失效引用、重复规则、万能角色设定和无关输出格式。
- 不保留示例中的真实人名或公司信息。

同时在 `submission/diagnosis.md` 简要记录修复了哪些根本问题。
