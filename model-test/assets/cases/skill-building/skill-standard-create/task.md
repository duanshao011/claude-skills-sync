# 任务

请根据 `input/brief.md` 创建一个可复用的周复盘 Skill，交付到 `submission/weekly-review/`。

Skill 需要真正改变Agent的工作方式，而不是把 brief 原样重写一遍。入口保持简洁，只有在需要详细评分规则时才读取 reference。

## 交付要求

- 必须有 `SKILL.md`，frontmatter包含name和description。
- 如详细规则较长，可以增加 `references/rubric.md`。
- 不创建README、安装说明、更新日志或无用占位目录。
- 说明输入不足时如何处理，不能编造一周完成事项。
- 输出必须区分事实、判断和下一周行动。
- 提供至少一项可验证的完成标准。
