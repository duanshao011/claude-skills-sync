# 准星

本地信息源监控阅读器，聚合关注博主的最新内容。支持 YouTube、公众号、抖音、小红书、B 站等渠道。

> ⚠️ **当前版本已迁移到独立仓库 `~/Documents/project/zhunxing`（github 为准）**。
> 本 skill 目录仅保留 SKILL.md 作为触发入口，实际应用代码在新版本目录。

## 使用方式（macOS）

新版本目录：`~/Documents/project/zhunxing`

```bash
# 启动（后台）
cd ~/Documents/project/zhunxing/app && node server.js &

# 访问
open http://localhost:3000

# 停止
lsof -ti:3000 | xargs -I{} kill {}
```

服务固定监听 `127.0.0.1:3000`（`.env` 中 `PORT` 可改）。每次启动会主动请求一次内容更新。

## 页面功能

- **三栏阅读器**：左侧博主/主题导航 → 中间文章列表 → 右侧正文
- **星标**：列表 hover 点 ☆、详情页按钮、快捷键 `S`；左栏有星标合集
- **主题分组**：把博主归到自定义主题，按主题聚合阅读
- **AI 摘要**：基于长文萃取规则生成结构化摘要（DeepSeek 驱动）
- **未读追踪**：未读角标，一键全部已读

## 配置

新版本 `.env` 在 `~/Documents/project/zhunxing/app/.env`：

- `PORT=3000` — 端口
- `DEEPSEEK_API_KEY` — AI 摘要（DeepSeek V4 Flash）
- `REDFOX_API_KEY` — 公众号/抖音数据（红狐数据）
- `XHS_API_KEY` — 小红书（Rnote API）
- `ALIYUN_AK_ID` / `ALIYUN_AK_SECRET` / `TINGWU_APP_KEY` — 通义听悟视频转写（抖音/YouTube 视频文案，未启用）
- `ANTHROPIC_API_KEY` — 可选 YouTube 标题翻译

密钥只存本地 `.env`，不进代码、不进版本库。

## 数据更新机制

- 不做后台定时任务，**每次打开主动抓取一次**
- 公众号数据来自红狐（RedFox）：每晚约 00:30 统一收录当天文章，**最多滞后约 16 小时**——当天发文次日凌晨才能查到。若某号最新文章停在几天前，通常是断更而非漏抓
- 数据存 `app/data/feeds.db`（SQLite），不上传云端

## 红线：AI 摘要绝不胡编乱造

- 摘要**必须基于原文**。正文少于 200 字或抓不到时，**不调用模型**，直接返回「内容不全，无法总结」并说明原因，不写缓存
- 数据源返回与请求不一致时（红狐 URL 直查偶发返回别的文章）拦截丢弃，正文错配比抓不到严重得多

## 公众号添加流程（搜索 → 确认 → 入库）

1. 「+ 添加信息源」→ 选「公众号」→ 输入名称 → 点「搜索」
2. 弹出候选账号卡片（头像 + 微信号 + 认证 + 简介），点击选中
3. 点「添加」→ 验证该号是否被红狐收录，**收录才入库**
4. 未被收录的号明确提示，不静默失败
