用户说"脚本转写小红书""转写笔记""转写小红书"等类似指令时触发。

每次**必须**按顺序完成：

2. 确认产品型号和关键词（见第一步）

---

## 执行流程

### 第一步：确认信息（必须）

转写前**必须**向用户确认以下两个信息：

1. **确认产品型号** — 读取脚本内容后，向用户确认是哪款产品（SollaWave AI音乐泳镜 / Holoswim 2Pro AR智能泳镜 / 其他）
2. **确认关键词** — 询问用户本次笔记希望埋入的搜索关键词是什么（不同笔记类型关键词不同）

> 示例话术："脚本内容已读取，这款是[SollaWave/Holoswim 2Pro]对吧？另外这次笔记你想埋哪些搜索关键词？"

确认后再动笔，不确认不写。

### 第二步：转写规则

#### 文风要求（小红书"直给"口吻）

- **要"直给"不要"评测"**：不写长段分析，不写"后来我发现""用了之后才知道"这种评测感的过渡。直接说痛点、直接给方案、直接推产品
- **口语化**：像朋友聊天，"姐妹们""举手""强推"等
- **短句+列表**：痛点用短句快速带过，选购要点用数字emoji列表（1️⃣2️⃣3️⃣）直列，产品卖点用短句逐行推进
- **emoji自然穿插**：每段1-2个，不堆砌，不每句都加
- **禁止书面语**："采用XXX技术""具有XXX功能""本产品"等一律不用
- **禁止夸大**：不说"最好""第一""碾压"等绝对化表述
- **术语转化**：骨传导→入耳式、九轴传感器→不用抬手就能看到数据、AR抬头显示→游着就能看数据

#### 内容结构（200字左右）

```
【钩子】1-2句，痛点开头，直接共情（姐妹们/举手类）
【痛点罗列】用逗号或顿号快速列2-3个痛点，一句话带完
【选购要点】数字emoji列表（1️⃣2️⃣3️⃣4️⃣），每行一句话一个点
【产品推荐】过渡句引出产品 → 核心卖点2-3个短句直推
【价值总结】一句话收尾（划算/方便/一步到位等）
【互动结尾】开放式提问引导评论（你们用什么泳镜？/有同款姐妹吗？）
【固定标签】根据产品型号选择对应标签组
```

#### 字数控制

- 正文（不含标签）：180-220字
- 标签不计入字数
- 超过250字必须精简

### 第三步：埋关键词

- 用户确认的关键词需自然融入正文（标题+正文各至少出现1次）
- 不要堆砌，读起来要像正常说话
- 关键词优先放在：标题、第一段、最后一段

### 第四步：固定标签（按产品型号选择）

**SollaWave AI音乐泳镜：**
```
#光粒SollaWaveAI音乐泳镜 #游泳耳机 #音乐泳镜 #智能泳镜 #泳镜 #近视泳镜 #游泳装备 #游泳 #Holosport泳镜 #游泳装备
```

**Holoswim 2Pro AR智能泳镜：**
```
#光粒Holoswim2pro智能AR泳镜 #智能泳镜 #泳镜推荐 #泳镜 #近视泳镜 #游泳 #Holosport泳镜 #游泳装备
```

> 其他产品型号的标签，转写时向用户确认。

### 第五步：输出格式

```
【标题】（含关键词，15-20字）

【正文】

【固定标签】
```

## 注意事项

- 脚本中的口播话术不能直接照搬，必须转化成小红书图文笔记的文风
- 脚本里有画面描述（镜头特写、下水画面等）的部分，转写时删除或转化为"亲测""实拍"等文字表达
- 脚本中的产品对比内容保留，但语气要更口语化
- 每次转写前必须确认关键词，不确认不动笔
- 标签只选对应产品的一组，不要混用

## 参考案例（"直给"格式标准）

> 以下为已验证通过的转写范例，转写时以此格式为基准。

```
**新手第一副泳镜怎么选？别再踩坑了🏊‍♀️**

姐妹们！刚学游泳买泳镜踩过多少坑的举手🙋‍♀️
漏水、起雾、压眼…游一次就劝退

选泳镜看这4点就够了👇
1️⃣ **贴合度** — 不是越紧越好，戴上贴不贴脸才是关键
2️⃣ **防漏水** — 游着游着进水最影响体验
3️⃣ **防雾** — 起雾就得不停擦，节奏全乱
4️⃣ **舒适度** — 戴久不压眼才愿意坚持

有固定游泳频率的姐妹，强推这款**光粒SollaWave音乐泳镜**🎧
一副顶五副！泳镜+耳机+手表+耳塞+防雾剂全集成
水下听歌超沉浸，还能语音播报游泳数据，再也不用老停下来看手表了
而且模块化设计，镜片胶圈绑带2年内免费换，长期超划算💯

你们游泳都用什么泳镜？评论区聊聊👇
```

**格式要点：**
- 钩子：姐妹们+举手emoji+痛点一句话
- 痛点：顿号连接，不展开
- 选购要点：数字emoji + 加粗关键词 + 破折号 + 一句话说明
- 产品推荐：过渡句（强推这款）+ 短句逐行推卖点
- 收尾：一句话（划算/方便）+ emoji
- 互动：开放式提问引导评论
