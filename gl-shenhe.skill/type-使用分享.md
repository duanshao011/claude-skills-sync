# 使用分享类审核指南

## 一、类型定义

**什么算使用分享：**
- 以个人真实使用经历为主线
- 图文笔记或口播分享，非完整评测结构
- 重点是"我用了之后的感受"，不是"这个产品有什么功能"
- 不要求完整模块覆盖，但要有真实感

**判断依据：** 脚本是否围绕个人经历展开，是否有"我"的视角和决策过程，是否不追求评测完整性。

**与深度评测的核心区别：**

| 维度 | 深度评测 | 使用分享 |
|------|---------|---------|
| 视角 | 评测者/KOL | 真实用户 |
| 结构 | 模块化、完整覆盖 | 经历线、可以只聊1-2个点 |
| 卖点密度 | 高，系统拆解 | 低，围绕核心体验展开 |
| 槽点要求 | 每模块带一个 | 整体有诚实评价即可 |
| 信任来源 | 专业性+客观性 | 真实感+共情 |

## 二、审核侧重（维度权重偏移）

| 维度 | 优先级 | 说明 |
|------|--------|------|
| 口语化风格 | ★★★ | 第一优先，像真人在说话 |
| 情感共鸣与信任建立 | ★★★ | 有经历弧线（怀疑→尝试→惊喜）+ 诚实说缺点 |
| 种草深度 | ★★ | 有具体场景/细节支撑，不是功能罗列 |
| 产品种草顺序 | ★★ | 先说体验故事，再说功能点 |
| 脚本结构 | ★ | 有基本逻辑即可，不要求完整模块 |
| 基础错误检查 | ★ | 参数准确，无禁忌词 |
| 节奏与承接 | ★ | 通顺即可 |

## 三、合格/不合格特征

### ✅ 合格的特征

- 开头有"我"的身份设定（如"每周泡三次泳池的游泳爱好者"）
- 有从怀疑到尝试的心理过程（如"又是噱头吧"→ "真香"）
- 有具体数字和对比（"3小时续航，一周充一次电足够"）
- 有场景细节（"自由泳转头换气、翻滚转身都不晃"）
- 口语化但有内容（不是空洞感叹"真香啊"）
- 主动说缺点建立信任（"低频稍弱""差点没听见救生员哨声"）

### ❌ 不合格的特征

- 开头用"想问各位云搭子们…"/"泳搭子们"自问自答套路
- 空洞感叹词："真香啊""打开新世界的大门""救大命""极简星人狂喜"
- 功能罗列+感叹："1个装备顶5个""二合一设计""IP68深潜级防水""一副搞定"
- 缺少真实心理转变过程
- 每个卖点独立出现、无关联，像产品页拆散了重排

### 审核核心问题

> **这篇内容像不像一个真实的人在分享自己的真实经历？**

## 四、子类型

### 4.1 口播使用分享

**推荐结构：**
1. 开头钩子 — 疑问句/经历切入
2. 痛点经历 — 之前用过什么、踩过什么坑（具体设备+具体问题）
3. 核心体验展开 — 围绕最核心卖点深入（体验为主，参数为辅）
4. 功能对比 — 对比替代品，讲体验差异不贬低
5. 加分项简述 — 不展开，一两句带过
6. 价格诚实评价 — 先说不适合谁，再说适合谁
7. 免费换件 — 放在价格段后，长期成本优势补充
8. 人群推荐 — 分类列出

**常见问题：**
- 全篇正面无槽点
- 卖点平铺罗列，没有主次和体验细节
- 用"宝藏/闭眼入/超顶"等模板词
- 竞品对比措辞过重
- 缺少具体数据和个人使用细节

### 4.2 图文笔记分享

**审核维度优先级（图文专属）：**

| 优先级 | 维度 | 说明 |
|--------|------|------|
| ★★★ | 口语化风格 | 像真实用户在说话，有"我"的视角 |
| ★★★ | 情感共鸣与信任建立 | 真实经历弧线 + 诚实说缺点 |
| ★★ | 种草深度 | 有具体场景/细节支撑 |
| ★★ | 产品种草顺序 | 先说体验故事，再说功能点 |
| ★ | 脚本结构 | 有钩子→体验过程→总结建议 |
| ★ | 基础错误检查 | 产品参数准确，无禁忌词 |

**图文笔记的特殊要求：**
- 卖点密度更低：500字内3-4个核心卖点，每个不超过80字
- 允许只深入1-2个点，不要求全面覆盖
- 重视开头和结尾，中间可以"散"一点

**功能描述可复用素材：**
- 音质："水下环境中中高频清晰，低频稍弱但整体饱满，像私人水下音乐会"
- 佩戴稳固："自由泳转头换气、翻滚转身均稳固"
- 续航："3小时续航，每次1小时游泳可维持一周使用"
- 防雾："使用1个多月，全程无起雾"
- 数据："每趟播报时间/距离/swolf，支持数据可视化分析"
- 一体化："不用带很多装备"的便利性

## 五、模块化卖点的种草逻辑（SW专属）

SW音乐泳镜脚本中"配件可更换"是必须提到的卖点：

**为什么必须提：** 899/1298元的泳镜，用户心智中泳镜=消耗品。不解决"贵了还会坏"的顾虑，转化过不去。

**正确位置：** 产品功能讲完之后的收尾段，用户已经对功能产生兴趣后再落成本。

**话术原则：** 隐性接种，不主动说"消耗品"标签。直接用解决方案暗示。"不用整副重买"比"你可能觉得是消耗品"更好。

**审核扣分线：**
- 完全没提配件可更换 → 种草深度扣分
- 主动使用"消耗品"等负面标签 → 口语化风格标注风险

## 六、常见问题速查

| 问题 | 影响维度 | 处理 |
|------|---------|------|
| 功能罗列无体验 | 种草深度 | 建议加"以前vs现在"体验对照 |
| 模板词堆砌 | 口语化风格 | 标注具体模板词，建议替换 |
| 缺经历弧线 | 情感共鸣 | 建议加"怀疑→尝试→惊喜"过程 |
| 全正面无缺点 | 情感共鸣 | 直接降级，标注信任建立不足 |
| 算账逻辑缺失 | 种草深度 | 高客单价产品必须做价值锚定 |
| 开头像品牌稿 | 口语化风格 | 建议换成个人经历/疑问切入 |
| 竞品对比措辞过重 | 基础错误 | 标注风险，给出客观替代 |
