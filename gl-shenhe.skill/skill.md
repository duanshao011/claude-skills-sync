# gl-shenhe

这是一个轻量入口，避免 Claude Code 启动或恢复会话时一次性读取过多内容。

使用方式：
1. 先读取 `references/full-instructions.md`，了解审核维度、评分方式和输出格式。
2. **识别脚本类型**，读取对应的type文件：
   - 深度评测（口播视频/完整结构/多维度拆解/横测）→ `type-深度评测.md`
   - 使用分享（个人经历/图文笔记/非完整评测）→ `type-使用分享.md`
   - 信息流（40-60秒/7段式结构/情绪种草/4维度精简审核）→ `type-信息流.md`
   - 标题正文审核（专项审标题和正文叙事质量/广告感，仅限发现页/信息流场景内容）→ `type-标题正文.md`
3. 不要默认读取全部支撑文件。仅在当前任务确实需要时，按需读取：
   - `product-knowledge.md`：涉及具体产品参数、功能边界、禁忌红线时读取。
   - `examples.md`：需要参考案例时，按类型标签搜索相关片段，不要整文件读取。
   - `persona-standard.md`：只有做人感评分或人感表达优化时读取相关片段。
4. 若文件很长，优先搜索关键词或分段读取，避免触发上下文压缩。
