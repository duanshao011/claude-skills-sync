# Search · 标题正文审核指南

## 一、类型定义

**什么算 Search · 标题正文：**
- 小红书笔记的标题+正文文案，无镜头/画面描述
- 用户主动搜索"XX测评""XX怎么样""XX值不值得买"后看到
- 核心任务：帮用户做决策——让想买的人买对
- 传递核心：产品、功能、是否值得
- 用户带着问题来，愿意花时间看，对广告容忍度高于 Feeds

**与 Feeds · 标题正文的核心区别：**

| 维度 | Feeds | Search |
|------|-------|--------|
| 用户状态 | 被动刷到，随时划走 | 主动搜索，带着问题来 |
| 标题策略 | 好奇心/情绪驱动，品牌名不出现 | 命中搜索关键词，品牌名可以出现 |
| 正文要求 | 人的时间线为主，情绪>信息 | 信息密度可以更高，但仍要有"我"的视角 |
| 广告感容忍 | 极低 | 中——用户预期看到产品内容 |
| 卖点数量 | 1-2个打透 | 3-5个系统覆盖 |
| 价格 | 禁止 | 可以有 |
| 槽点/缺点 | 不需要 | 必须有——全正面=不可信 |

---

## 二、审核维度（5维度）

| 维度 | 满分 | 核心问题 |
|------|------|---------|
| 标题搜索力 | 30 | 能被搜到吗？前10字有核心搜索词吗？搜索词+人的元素都到位了吗？ |
| 信息密度+完整度 | 25 | 用户搜进来的问题被回答了吗？3-5个维度展开了吗？ |
| 诚实度 | 20 | 有没有缺点/不适合谁？全正面=广告=不可信 |
| 正文结构+可读性 | 15 | 分段清晰、有递进逻辑、能扫读吗？ |
| 基础错误 | 10 | 参数准确、无禁止词、标签和关键词齐全 |

> ⚠️ 文案美化技巧（场景强化/巧用比喻/贩卖焦虑等）**不适用于 Search 类型**。Search 用户要精准信息和诚实判断，不是情绪渲染。过度美化反而破坏信任。

---

### 维度1：标题搜索力（30%）

**核心判断：** 用户搜什么词能找到这条内容？搜到之后会点进去吗？

| 分数段 | 特征 |
|--------|------|
| 9-10 | 前10字内植入核心搜索词，同时有人的元素（身份/时间/场景），结构=搜索词+人的价值 |
| 7-8 | 有搜索词但偏后，或有人元素但比较泛 |
| 5-6 | 有搜索词但纯产品标题，无人感 |
| 3-4 | 标题像Feeds但无搜索词，搜不到 |
| 1-2 | 标题完全无搜索意识，无搜索词无信息价值 |

**标题公式：** `[品牌/品类词] + [使用场景/人群] + [核心价值]`

**好标题 vs 坏标题：**

| ✅ 好标题 | ❌ 坏标题 |
|----------|----------|
| 光粒Holoswim 3智能泳镜｜用了三个月的真实感受 | 这副泳镜改变了我的游泳方式 |
| 5款智能泳镜横测｜游泳爱好者实测对比 | 到底买哪个？全部买来试了！ |
| 近视也能用的智能泳镜｜200-600度定制方案实测 | 近视人的福音来了 |
| 智能泳镜值不值得买？游了半年说点真话 | 游泳好物分享 |

**关键词分层：**

| 用户层级 | 搜索词类型 | 示例 |
|---------|----------|------|
| 泛用户 | 场景词/人群词 | "游泳装备推荐" |
| 高潜用户 | 品类词/对比词 | "智能泳镜 哪个好" |
| 精搜用户 | 品牌词/产品词 | "光粒泳镜 测评" |

**禁止：**
- 纯Feeds式标题（无搜索词、纯情绪驱动）→ Search 根本搜不到
- "科技/黑科技/神器"等禁止词——Search 场景同样禁止，数据实证强关联低停留

---

### 维度2：信息密度+完整度（25%）

**核心判断：** 用户搜索时脑子里带着的问题，读完后被回答了吗？

| 分数段 | 特征 |
|--------|------|
| 9-10 | 3-5个维度系统覆盖，每个维度有场景/数据/结论，信息密度高但不臃肿 |
| 7-8 | 主要维度覆盖，个别维度偏浅或缺失 |
| 5-6 | 覆盖了2-3个维度但深度不够，用户看完还要再去搜别的 |
| 3-4 | 信息量类似Feeds——只讲了1-2个点，搜索用户不够用 |
| 1-2 | 空洞无实质内容 |

**审核要点：**
- 覆盖了几个维度？搜索用户关心的核心问题（功能/体验/缺点/适合谁）都答了吗？
- 每个维度有没有具体信息？不是"很好用"，而是"用了三个月，每周三次，续航一周充一次"
- 有没有因为追求"可读性"而牺牲了信息量？（Feeds 思维入侵 Search）

---

### 维度3：诚实度（20%）

**核心判断：** 这篇内容是在帮用户做判断，还是在推销？

| 分数段 | 特征 |
|--------|------|
| 9-10 | 主动说缺点/使用注意/不适合谁，结论有判断不模糊 |
| 7-8 | 有诚实评价但不够具体，或"不适合谁"比较模糊 |
| 5-6 | 提到了一点不足但轻描淡写，整体还是正面为主 |
| 3-4 | 全篇正面，无任何槽点或限制说明 |
| 1-2 | 纯广告稿 |

**审核要点（红线）：**
- 全篇无槽点/无"不适合谁" → 诚实度直接降级，标记红线
- 槽点是否具体？（"App有时候同步慢"比"有些小问题"可信得多）
- "不适合谁"是否明确？（"纯休闲泡水的没必要买"比"大家根据需求选择"有用得多）
- 结论是否模糊？（"各有优劣"等于没说，Search 用户要的是判断）

---

### 维度4：正文结构+可读性（15%）

**核心判断：** 分段清晰吗？能扫读吗？有递进逻辑吗？

| 分数段 | 特征 |
|--------|------|
| 9-10 | 分段清晰，标题党+小标题分隔，维度间有递进（由基础到体验），可扫读 |
| 7-8 | 结构完整但递进感不强 |
| 5-6 | 有分段但逻辑跳跃，或过长的段落影响扫读 |
| 3-4 | 大段文字无分隔，或结构混乱 |
| 1-2 | 无结构，流水账 |

**审核要点：**
- 是否用小标题/emoji/空行做视觉分隔？
- 维度顺序是否合理（先基础后体验，先易感知后深层次）？
- 段落长度是否适合手机屏幕扫读？

---

### 维度5：基础错误（10%）

- 产品名称、型号正确
- 技术参数准确（对照 `product-knowledge.md`）
- 功能边界正确，无夸大
- 禁止词：科技/黑科技/神器/方案/智商税
- 话题标签含搜索关键词（3-5个：1个大词+2个长尾词+1-2个热门话题）

---

## 三、评分等级

| 分数 | 等级 | 处理建议 |
|------|------|---------|
| 85+ | 可发 | 直接用，最多改几个字 |
| 70-84 | 润色 | 方向对，个别表述调一调 |
| 55-69 | 修改 | 有明显问题，但框架可保留 |
| <55 | 重写 | 核心问题多，需要重新构思 |

每个维度在满分范围内直接打分（如满分30的维度，直接打0-30分）。总分 = 各维度得分之和，满分100。

## 四、Search · 标题正文 红线

| 序号 | 规则 |
|------|------|
| S-TB-1 | 标题前10字内必须植入核心搜索词 |
| S-TB-2 | 全篇无槽点/无"不适合谁" → 诚实度直接降级 |
| S-TB-3 | 禁止词：科技/黑科技/神器/方案/智商税 |
| S-TB-4 | 话题标签必须含搜索关键词 |

## 五、SEO 关键词布局（审核参考）

按权重排序的9个关键词位置：
1. **标题**（最高权重，前10字必须植入）
2. **正文开头100字**（嵌入2-3次主关键词）
3. 正文中段
4. 正文结尾
5. 图片上的文字
6. 话题标签（3-5个）
7. 评论区
8. 账号简介
9. 收藏夹名称

**70-30法则：**
- 70% 长尾关键词（"适合近视的智能泳镜"）——竞争小，精准度高
- 30% 热门关键词（"智能泳镜推荐"）——流量大
