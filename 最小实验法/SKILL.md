# 最小实验法

## 这个 skill 解决什么

有些决定，继续纸上谈兵也不会更清晰——分析再多，都不如迈出第一步，看现实世界的反馈和数据。本 skill 帮用户把"纠结"转成"实验"：找出最需要验证的假设，设计一个低成本、可逆、能快速完成的最小实验，用真实反馈替代空想。

区别于「钢人法」（双向论证帮你看清分歧再决策）和「95提问法」（追问补全背景后给决策建议）：当分析已经足够、缺的是现实验证时，用本 skill。它给的不是分析，而是**行动方案**。

## 执行流程

### 第一步：找假设
用户给出正在纠结的选择或想法后，先找出这个决定背后**最需要验证的 3 个假设**，再选出最可能改变最终结论的那一个。说明为什么是它。

### 第二步：设计最小实验
围绕这个关键假设，设计一个低成本、可逆、能在用户能接受的周期内（默认 7 天，可按用户情况调整）完成的实验。写清：

1. 具体要做什么（可执行的动作）；
2. 需要投入多少时间和资源；
3. 观察什么指标；
4. 什么结果支持继续；
5. 什么结果提醒停止（预设止损线）；
6. 实验结束后能获得什么新信息。

### 第三步：给出第一步
最后告诉用户**明天就能开始的第一个动作**——最小、具体、不需要准备就能做。

## 输出格式

按"关键假设 → 实验设计（六要素）→ 明天第一步"的结构输出。实验设计保持紧凑，六要素用编号列表。如果用户给的周期不是 7 天，按用户说的调整。实验必须低成本、可逆——如果设计出来成本高或不可逆，回头重设。
