# 双层解释法

## 这个 skill 解决什么

很多人喜欢让 AI"把我当小学生解释"，听懂了类比，但真正的机制还是一团雾——停留在"好像懂了"的阶段。本 skill 用**小白版 + 专业版两层解释**，既听得懂，又真正学到机制。

区别于「费曼思维」（以教学促理解、用类比拆解复杂概念）：双层解释法输出更结构化——固定两层 + 对应关系 + 易错点 + 自测题，适合快速建立概念的第一印象并检验是否真懂。两者可配合：先双层解释，再用费曼检验。

## 执行流程

用户给出想学的概念或问题后，分两层解释：

### 第一层：小白版
用生活化的语言和一个具体例子，让完全没有基础的人也能听懂。

### 第二层：专业版
使用准确术语，讲清：
- 核心机制（它是怎么运作的）；
- 适用边界（什么时候成立、什么时候不成立）；
- 常见误解（新手最容易错的理解）。

### 最后整理三项
1. 小白说法与专业术语的对应关系（列表对照）；
2. 用户最容易理解错的地方；
3. 3 个用于检查是否真正理解的问题（自测题，供用户自己回答检验）。

## 输出格式

分区块输出，小白版在前、专业版在后，术语对照表用两列列表。控制篇幅：概念简单就短，概念复杂再展开。最后自测题不用给答案，留给用户自测；用户答错或答不出，回到对应层重新解释。
