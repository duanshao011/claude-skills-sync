# 抖音内容营销与投放知识库

> 适用：Holoswim / SollaWaveAi 音乐泳镜（千元+客单、新品类需教育、小众垂直）在抖音的内容营销与投放。
> 本 skill 固化了多轮对话中**已纠正的错误认知**，避免重复踩坑。

---

## 0. 一句话定位

抖音是「内容场 + 交易场 + 广告场 + 达人场」四场协同的机器。
- **卖货本职 → 巨量千川**（成交/ROI 导向，必须绑抖店）
- **打品牌声量 → 巨量营销**（开屏/TopView 等，全域）
- **找达人 → 巨量星图 / 精选联盟**

---

## 1. 巨量引擎后台四象限（最常混淆，已纠正）

**关键纠正**：巨量营销和巨量千川不是「一个竞价、一个品牌」，而是**各自下面都有「竞价投放」和「品牌投放」**。区别在**场景**，不在买法。

- 巨量营销 = 全域营销（抖音 + 头条 + 西瓜等）
- 巨量千川 = 抖音电商闭环（必须绑抖店）

| 入口 | 本质 | 必须抖店 | 主要目标 | 典型产品 |
|---|---|---|---|---|
| 巨量营销·竞价 | 全域效果广告 | 否 | 线索/下载/APP/站外电商 | 信息流竞价、搜索竞价 |
| 巨量千川·竞价 | 电商效果广告 | **是** | 短视频挂车/直播间成交，按ROI | 商品推广、直播推广 ★日常卖货主战场 |
| 巨量营销·品牌 | 全域品牌广告 | 否 | 大曝光、新品上市、赛事赞助 | 开屏、TopView、信息流品牌位、搜索品牌专区 |
| 巨量千川·品牌 | 电商场景品牌广告 | 建议有 | 给直播间/大促引流保量 | 直播间品牌广告、电商开屏、TopFeed |

**选择逻辑**：先看有没有抖店 → 再看目标（成交/线索/声量）→ 最后看预算阶段。
- 日常 90% 精力：巨量千川·竞价
- 大促冲直播间：千川·品牌 + 千川·竞价组合
- 赞助赛事/新品刷全网：巨量营销·品牌（开屏）
- 巨量本地推（线下门店）、巨量星图（达人撮合）不是投放主战场

## 2. 工具生态地图

| 工具 | 角色 | 关键说明 |
|---|---|---|
| 抖音小店 | 底座 | 必须先开，千川才能投成交 |
| 巨量千川 | 主战场(90%精力) | 商品推广/直播推广，按ROI优化 |
| DOU+ | 轻量加热 | 单条视频几十块补自然流；**注意：加了精选联盟购物车的视频不能投DOU+** |
| 巨量云图 | 人群数据台 | 看A3、圈人推千川 |
| 巨量星图 | 达人商单撮合 | 对标小红书蒲公英；投后6大板块度量 |
| 精选联盟 | 纯CPS分销 | 达人主动挂车赚佣，不走星图、免商单费 |
| 巨量营销 | 综合品牌/线索 | 全域开屏等 |
| 巨量本地推 | 线下门店 | 一般用不上 |

> 千川「种草通」属巨量引擎侧（蓄水+A3度量），「商品全域推广」属千川侧（成交收割），是上下游接力，不是二选一。

## 3. 达人合作全路径

**三通道**：
- **星图商单**：官方撮合，内容费+10%平台费；有「纯种草不挂车」任务也有挂车任务；投后看6大板块数据
  - **商单视频推送投流（重点）**：所有星图任务类型（指派/投稿/招募/星广联投）发布后的视频，均支持在「达人交付情况 → 推送视频投流」一键推送至 **巨量营销**（效果&品牌）和 **千川** 做追投放大（官方："所有星图视频均支持一键授权推至巨量营销"）。前置：下单勾选【启用营销投放】抓授权，或发布后手动推；授权最长365天、推送账户限500个；⚠️必须走星图推送链路，勿下载本地上传（脱钩卡审）；推巨量营销支持全组件，推千川仅认闭环购物车；曝光/互动累计回原视频
  - 指派任务：客户指定达人，1v1，达人门槛通常≥10万粉
  - 投稿任务：客户发任务N个达人投稿瓜分奖金池，门槛≥1万粉
  - 招募任务：批量招募中小达人，达人报名/客户反选/定向邀约。**2024年起客户侧定向邀约门槛已拓展至1000粉-500W/5000W**（具体以任务模式为准：一口价模式1K-500W，按效果结算模式1K-5000W），不是1万起步
  - 星广联投：服务商反选+系统联合自然/广告流量投放，门槛≥1万粉
- **精选联盟**：纯CPS，必挂车，按成交付费；双佣金玩法（日常佣X+投流佣Y，达人选双佣、你千川追投时按Y结算）
- **私下/寄样**：最轻量，无商单无平台费

**多内容线投放计划组织原则（实操）**：
- 平台层：巨量营销 vs 千川是**两套独立后台+独立钱包**，本就不能"一个计划跨平台"，系统天然分开，无需选
- 同平台内（如都在巨量营销投种草）：**蓝V线 与 达人星图线 分不同计划/广告组，勿混一计划分单元**。原因：①优化目标不同(蓝V投商品访问/粉丝，达人投播放/互动/种草) ②定向人群不同(品牌自有vs达人粉丝/兴趣) ③出价预算策略不同 ④归因复盘需分清两线贡献
- 推荐结构：巨量营销{计划A=蓝V种草线，多条视频创意赛马；计划B=达人星图种草线，多条授权视频创意赛马}；千川{计划C=蓝V挂车成交；计划D=达人星图挂车成交(如有)}
- 每计划内放多条创意自动赛马，别拆太碎（预算分散拉不长学习期）；**若想精确对比每条视频效果/独立控预算，也可一个单元挂一个创意**（精细打法，代价是单元数暴增、失去系统自动优选，需手动关停差素材），适合素材量不大时
- 蓝V是自家账号，投巨量营销直接用蓝V号，无需合作码（合作码仅给达人用）

**后台项目/单元命名规范（完整版，适配巨量营销新版后台）**：
- **核心区分逻辑（巨量营销新版后台）**：后台左侧"项目"即推广/广告计划，创建第一步即强制选择并绑定一个抖音号主体；**每个达人单独建一个项目**。一个项目（达人）内可建多条创意，每条创意从该达人授权视频里选具体视频。同产品线/同来源的多个达人项目，靠统一命名前缀在后台筛选归集。注意：这是"一个达人一个项目"，不是"一个视频一个项目"——同一达人的多条授权视频放在同一项目多条创意即可，不必每条视频单开项目。跨达人必须分开项目是巨量营销抖音号推广的平台机制（项目创建时即锁定一个抖音号主体）。**维度本质：巨量营销项目维度=抖音号（一个号一个项目），蓝V官号本身也是一个抖音号，故一个官号项目内可建多个单元（对应官号多条视频），与达人单号单项目逻辑一致。这与小红书蒲公英/聚光以"计划/投放活动"为维度（一个计划可含多达人多笔记）的机制不同。**
- **项目名（每个达人一个项目）**：`[产品简写]_[来源]_[达人名/账号名]_[目标]_[日期]_[序号]` → `SW_星图招募_香菜_种草_20260901_01` / `SW_星图招募_丸_种草_20260901_01` / `SW_蓝V_官号_种草_20260901_01` / `3PRO_星图指派_李教练_种草_20260901_01` / `SW_蓝V_官号_成交_20260901_01`(千川)
- **单元名（同一达人项目内按视频拆单元）**：`[达人名/视频名]_[目标]_[出价]_[序号]` → `香菜_视频1_互动_oCPM_01` / `官号_笔记1_商品访问_oCPM_01`(千川)。若一个达人只有一条视频可简化为`视频1_互动_oCPM_01`
- **简写对照**：产品线 SW=SollaWaveAi(音乐泳镜)，3PRO=Holoswim 3PRO(智能泳镜)；来源 蓝V/招募/指派/合作码；目标 种草/互动/访问/成交/搜索（挂车状态靠平台隐含：巨量营销默认不挂、千川默认挂，命名中不写）
- **博哥当前项目创建示例**：投 3 个星图招募达人种草 = 建 3 个项目：`SW_星图招募_香菜_种草_20260901_01`、`SW_星图招募_丸_种草_20260901_01`、`SW_星图招募_贾楠_种草_20260901_01`。后台筛选时搜 `SW_星图招募_种草_` 即可聚合查看总消耗。
- **原则**：统一英文下划线无空格；日期用`YYYYMMDD`；素材迭代加`_v01/_v02`；命名够复盘用即可，别过度堆字段；同一来源/目标的项目用统一前缀聚合

**关键边界（多次澄清）**：
- 走星图**不强制挂车**（有纯种草不挂车任务；部分任务甚至要求不得挂车）
- ⚠️ **星图商单视频发布成功后不可补挂/修改购物车组件** → 「先种草火了再后挂车」在星图走不通，需两条内容分工（星图纯种草 + 精选联盟挂车/直播转化 + 千川追投）
- **水下挂车 → 千川能投**：条件=达人走精选联盟挂你车 + 开「托管授权」；跳过星图省10%但丢星图6大板块数据、需自建看板
- **水下不挂车 → 千川投不了**（只认闭环购物车）；但品牌方仍可放大这类内容，走两条路：
  ① **DOU+ 代投**：手机端直接帮达人视频「上热门」，目标=播放/互动/粉丝/主页访问（轻量种草加热）
  ② **巨量引擎 AD · 广告合作码**：达人开启「广告合作码」→ 品牌方申请视频授权 → 在巨量营销(竞价/品牌)投达人原视频或蓝V重发素材（可配小蓝词引导搜索、落地页、品专承接）。这是**非星图达人视频做专业投流的正解**
- 品牌方可用 **DOU+ 代投他人视频**；不走星图也能千川投达人挂车视频（需托管授权）
- ⚠️ 上述两条路投的是**种草/曝光/互动**，不是直接成交（无车）；收割靠用户看后搜 → 千川截搜索/商城成交（需你自己的挂车视频/直播间）

## 4. 5A / A3 人群模型

按**行为互动深度**分（非人口属性）：
O机会 → A1了解(被动曝光) → A2吸引(浅互动) → **A3问询/种草(想买没买)** → A4购买 → A5拥护

- **A3 判定（近15天行为，命中即算）**：主动搜品牌词>1次、进直播间≥6次/看>5分、商品点击/加购、星图视频深度观看、关注主页/私信等
- **圈定3法**：①云图直接选A3层 ②行为自建人群包(排除已购避免重复花钱) ③商品5A下钻看单品
- **看数入口**：巨量云图(主力) / 星图投后报告-人群资产 / 抖音电商罗盘·生意经 / 千川种草通追投
- **历史数据回补**：未开通平台也会同步显示历史人群（底层行为日志一直记录）；极速版即开即用见历史资产；品牌版需主动申请回溯；5A时间窗 A3=近15天、A4=近365天（若近半月无互动，A3可能偏空）

## 5. 巨量云图 极速版 vs 品牌版

| | 极速版 | 品牌版 |
|---|---|---|
| 视角 | 投放/抖店账户维度 | 品牌维度全量资产 |

| 自然内容/品牌搜索 | ❌ 不含（看后搜去星图投后看） | ✅ 含 |
| 门槛 | 免费即开即用，绑定投放/千川账号 | 商标证 + **90天消耗>30万** + 40-60天周期 |
| 建议 | 先开，马上看已沉淀A3 | 消耗过30万再做深度分析 |

## 6. 抖音 vs 小红书 种草逻辑

- 小红书平台职能对等：蒲公英(找达人，对标星图) / 灵犀(看AIPS人群资产，对标云图) / 聚光·乘风(投放) / 薯条(加热)
- **AIPS = A认知-I兴趣-TI深度兴趣-P购买-S分享（五段，TI对标抖音A3）**；主看板在**灵犀**，不是蒲公英
- 小红书已是「站内市集闭环 + 站外种草直达(红猫/红京/红美) 双轨」，非被锁死外循环
- 抖音=漏斗模型（先广后窄成交）；小红书=反漏斗模型（人群破圈+搜索心智）
- 协作建议：小红书种草 + 抖音收割（千元+新品类正确打法）

## 7. SollaWaveAi 选型建议

- 千元+客单 / 新品类需教育 / 小众垂直 → **先种草蓄水(A3)再收割，别直接硬投转化**
- 推荐打法：**大闭环（头部不挂链起势 → 垂类挂链测素材 → 千川种草通放大）+ 千川种草通**
- 三转化卡点破解：价格高（价格锚点+分期）、怀疑功能（实测水下听歌/防水）、不知适不适合（场景化+配件免费更换打消售后顾虑）
- A3→A4 转化：千川追投(排除已购) + 搜索拦截 + 直播间承接 + 私域；盯云图A3→A4流转率、千川ROI、抖店商品卡成交

## 8. 零基础上手清单

- **必懂5词**：挂车、人群包、A3、ROI、控成本投放(新手别用放量投放)
- **5步循环**：建计划 → 选素材 → 圈人群(A3包排除已购) → 设预算+出价 → 看数据优化
- **每天盯3数**：ROI、转化成本、点击率/千次曝光成本
- **新手3坑**：别硬投成交(先有A3)、别只看播放量、别频繁改计划(学习期≥3天)
- **第一周3件事**：确认抖店已开、开云图极速版、拿A3包建第一条商品推广计划

## 9. 常见误区速查（已纠正）

| 误区 | 正解 |
|---|---|
| 营销=竞价、千川=品牌 | 两平台各有竞价/品牌，按场景分（全域 vs 电商闭环） |
| 巨量营销和巨量竞价是两个并列平台 | 巨量营销 ⊇ 竞价投放，「巨量竞价」=巨量营销·竞价投放子入口，是层级包含非并列 |
| 星图必须挂车 | 有纯种草不挂车任务 |
| 先种草火了再后挂车 | 星图商单视频发布后不可补挂车，需两条内容分工 |
| AIPS在蒲公英看 | 在灵犀看 |
| AIPS四段 | 五段（A-I-TI-P-S） |
| 小红书只能外循环 | 双轨（市集闭环 + 种草直达） |
| 没开通平台前的数据会丢 | 底层一直记录，开通即同步历史（A3看近15天窗口） |

## 10. 巨量千川后台找不到"投放/新建计划"按钮排查（零基础高频坑）

**现象**：进了千川页面，但看不到"新建计划""竞价投放"等入口，无法操作投放。

**原因1（最常见·入口点错）**：在巨量引擎工作台只点了顶层「巨量千川」图标，进的是千川**门户/概览页**（只有数据、资产、学习中心）。必须**展开左侧菜单，点「巨量千川 → 竞价投放」子项**，才进到真正的投放操作台；操作台左侧有「推广」菜单，里面才是「新建推广计划」。

**原因2（未绑抖店）**：千川必须绑抖店才能投成交。店铺未绑定 / 非正常营业 / 保证金未缴 → 无竞价入口，提示"暂无权限 / 未开通"。

**原因3（账户未开通或未充值激活）**：新账户需申请开通，且**首次充值 ≥1000 元**才激活竞价模块；未激活时入口灰色/不可点，可能只显示"智能推广"。

**正确操作路径（PC端）**：
巨量引擎工作台(或 qianchuan.oceanengine.com) → 左侧「巨量千川」展开 → 点「竞价投放」→ 投放台左侧「推广」→「新建推广计划」→ 选「商品推广」(单品) 或「直播间推广」→ 投放模式选「全域推广·商品自选」(新手别选全店托管) → 设日预算(新计划≥300元) + 投放方式「控成本投放」 + 定向「排除已购」 → 绑定商品 + 上传挂车视频素材 → 提交审核(通常30分–2小时) → 通过后自动投放。

## 11. 水下无车达人视频的投流平台与可投目标（高频实操）

**场景**：达人自己账号发布、不走星图、没挂车，品牌方想放大这些内容。

**先明确：抖音投放在哪个平台？**
- 卖货成交本职在**巨量千川**，但千川只认闭环购物车 → **无车视频千川投不了**。
- 这批内容要放大，平台去 **DOU+（抖加）** 和 **巨量引擎 AD（巨量营销）**。

**品牌方可以投吗？两条合法路：**

| 路径 | 平台入口 | 操作前提 | 投在哪 | 计费 |
|---|---|---|---|---|
| ① DOU+ 代投 | 抖音App：达人视频→分享→左滑→「DOU+帮上热门」 | 无需授权，直接帮投；视频带营销属性需账号升级 | 达人原视频 | 100元起，加热 |
| ② 广告合作码 | 巨量引擎 AD（竞价/品牌） | 达人开「广告合作码」→ 品牌方申请视频授权 → 通过 | 达人原视频 或 蓝V重发素材 | oCPM/品牌GD |

**路径②「广告合作码」流程**（官方机制，专解非星图达人投流）：
1. 达人在抖音App：我→设置→账号与安全→我的合作码，开启并生成合作码发给品牌方
2. 品牌方在投放端申请视频授权，达人同意 → 完成授权（授权期可选7/30天或1-60天自定义）
3. 品牌方在巨量营销建投放计划：选「原视频投放」(达人账号上投) 或「素材投放」(蓝V重发)
4. 授权期内可投，不影响达人自然流量

**可投目标（按路径）：**

| 路径 | 可投目标 | 说明 |
|---|---|---|
| DOU+ | 播放量/互动量、粉丝量、主页访问量 | 轻量种草，拉A3；不挂车就别选带货目标 |
| 巨量营销·竞价 | 点击、互动、调起(APP)、表单留资、商品访问、小蓝词搜索引导 | 可配落地页/品专承接搜索；能做精准人群定向 |
| 巨量营销·品牌 | 开屏、TopView、信息流品牌位、搜索品牌专区 | 大曝光/新品上市/赛事赞助 |

**收割衔接（关键）**：这些路投的是种草/曝光，不直接成交。要成交 → 用户看后搜"音乐泳镜" → 你用**千川截搜索/商城**(需自己挂车视频/直播间) 或 **抖音搜索品专** 收口。

**落地建议（针对已有一批水下种草笔记）**：
- 最轻量：筛自然互动达标的，DOU+ 代投加热，目标选「互动量」或「主页访问量」→ 拉A3
- 想规模化可控：找达人开「广告合作码」授权，在巨量营销建竞价计划投(种草/互动目标)+配小蓝词引导搜索
- 想收割：等A3蓄水够，用千川截搜索/商城成交

## 12. 巨量营销竞价(种草) + 千川(挂车) 双线并行（已确认可共投）

**结论**：可以一起投，这是抖音官方推荐的「种割双轨」。两线独立账户、并行跑、互不冲突。

- **蓄水线**：巨量营销·竞价 → 投信息流种草笔记（达人/蓝V发、无车）→ 目标选种草/互动/主页访问 → 拉A3蓄水
  - 达人笔记需走「广告合作码」授权（见第11节②）；蓝V自己发的种草笔记可直接在巨量营销投，无需授权
- **收割线**：巨量千川·竞价 → 投挂车视频/直播间 → 目标选成交/ROI优化 → 直接卖货
- **协同版（更省事）**：蓄水线跑出的 A3 → 巨量云图沉淀人群包 → 直接推千川「追投A3」收口（把两线用数据连起来）

**3个关键提醒**：
1. **频控叠加**：同一用户可能两边都被触达（都刷到）。建议千川定向勾「排除已购」，种草线用互动目标、不抢成交流量，避免自己跟自己竞价抬价
2. **预算分开管**：两线账户独立，分别设日预算、分别看 ROI；别混在一起算不清哪条线赚钱
3. **素材不共用**：种草线是无车笔记、收割线是挂车视频，两条素材线分开备，别把挂车视频丢进巨量营销种草计划（会考核变、且加了购物车的视频不能投DOU+）

**一句话**：种草归营销、成交归千川，两线并行跑，数据用云图A3串起来做协同收割。

| **oCPM**（优化千次曝光出价） | 按效果付费的聪明投法：你跟系统说"一个订单成本控制在50元"，系统自动找最可能转化的人，按"每被看1000次"扣费，但保证尽量贴近你的目标成本 | 你跟中介说"帮我找真想买房的人，成交一单我给X元佣金"，中介自己挑人，按找到的人头算钱，但保证找的是真有意向的 | 日常卖货/种草/收线索全用它（千川·竞价 + 巨量营销·竞价 都是 oCPM） |

| **种草通** | 千川里的蓄水模块（属巨量引擎侧），为电商成交铺垫 A3 | — | 想做闭环成交就别把挂车藏着 |

## 14. 新品牌抖音投放四阶段打法（SollaWaveAi 真实路径）

**用户模型确认**：「巨量营销蓄A3 + 千川承接」正确，即官方「种割双轨/外种内收」。
**必要补充**：A3 不只来自巨量营销，对你们有三大引擎——① 达人种草(星图/水下+DOU+加热/精选联盟挂车) ② 巨量营销竞价加热笔记(放大器) ③ 蓝V自然内容。巨量营销是放大器，达人内容才是新品牌A3主引擎。

**新品牌核心差异**：0 A3、0搜索心智、0粉丝信任、算法不认识人群 → 直接投千川成交=让陌生人下单，ROI常<0.5翻车。**必须把种草蓄水前置加重、千川成交后置。**

| 阶段 | 时间 | 重心 | 动作 |
|---|---|---|---|
| 0 基建 | 开通前 | 底座 | 抖店(营业+保证金)、蓝V、星图+精选联盟、云图极速版、备5-10条素材 |
| 1 种草测试 | 0-2周 | 找谁感兴趣 | 达人种草当主力(垂类达人发体验)；巨量营销·竞价投「互动/主页访问」目标；DOU+测内容方向；不考核ROI |
| 2 蓄水验证 | 2-6周 | A3滚大 | 互动用户打包种子人群包；千川浅层投「商品点击/直播间进入」帮算法建模；达人精选联盟开始挂车测转化 |
| 3 收割放大 | 6周+ | 冲ROI | 千川切「成交/ROI」；直播间常态化；搜索/商城拦截；云图A3推千川追投；双线并行放量 |

**新品牌5注意**：①别一上来猛投千川成交(没A3又贵又跑不动) ②达人信任背书>蓝V自吹(新品牌无粉丝，垂直达人=信任杠杆) ③搜索心智从0建(种草钩出"看后搜"，用户搜"音乐泳镜"你要在) ④内容力>投流力(先打磨实测水下听歌/防水可种草素材) ⑤千川冷启动目标由浅入深(进入/观看→商品点击/涨粉→最后成交，别跳步)

**一句话**：框架对新品牌也成立，节奏上蓄水更早更重、千川成交更晚，等A3池够大再开闸。

## 15. 蓝V已发布挂车视频 · 投千川具体操作（最直接路径）

**前置**：抖店正常营业 + 蓝V已发布视频并挂好商品购物车 + 千川账户开通并充值激活。

**关键省事点**：千川「全域推广」会**系统自动拉取蓝V主页近180天的挂车视频（智选素材）**，也能在「自选」里手动勾选主页视频——**不用重新上传，直接用已发布的这条视频投**。

**步骤（PC端）**：
1. 巨量引擎工作台 → 左侧「巨量千川」**展开** → 点「竞价投放」子项 → 投放台左侧「推广」→「新建推广计划」
2. 推广目标：单品静默出单选「商品推广」；有直播选「直播间推广」
3. 投放模式：选「**全域推广 → 商品自选**」（标准推广已停建，主推全域；别选全店托管）
4. 选商品：从抖店选已挂车的那个商品
5. 素材设置：
   - 智选：系统自动拉取主页挂车视频 + 商品卡（默认勾选，无需操作）
   - 自选：点「自选投放素材」→ 来源选「抖音主页视频」→ 勾选要投的那条已发布挂车视频（可加创意标题）
   - 排除某条主页视频：在智选里点「排除」
6. 投放方式：新手选「**控成本投放**」；优化目标选「**商品购买 / 支付ROI**」（直接优化成交，别选点击/进入等浅层）
7. 定向：基础按人群（地域排除偏远、性别年龄按品类）；**务必勾「排除已购用户」**；无历史数据先「系统智能推荐」
8. 日预算：测试期单计划 100-300 元（建议300-500），同时开 3-5 条计划差异化（不同素材/定向）筛优放大
9. 出价：参考系统建议价，新号上浮 10%-20% 起量；稳定后每24h降5%-10%
10. 提交审核（30分–2小时）→ 通过后自动投放

**注意**：
- 全域推广「不区分自然和付费流量」，支付ROI = 整体支付GMV(含自然) ÷ 消耗，看的是这条链接整体ROI
- 新建计划**至少观察24-72小时再调**（学习期），别频繁改价改预算
- 数据盯：整体支付ROI、转化成本、千川带来订单数；ROI<1 立即调，无起色关停
- 手机端也能投：抖音App → 我 → 创作者服务中心 → 小店随心推 → 千川入口 → 极速推广（新手小额测素材，100元起）

## 16. 巨量营销 vs 巨量千川 · 资金账户是否通用（零基础高频疑问）

**结论**：**默认不是同一个账户，资金是隔离的，要分别充值。**
- 主体资质是同一个（同一企业、同一巨量引擎工作台登录、共用企业认证），但**广告资金钱包是分开的两个**：
  - 巨量营销（巨量广告）钱包 → 只能投巨量营销
  - 巨量千川钱包 → 只能投千川
  - 互相不通，在巨量营销充的钱投不了千川，反之亦然（官方明确"两者账户体系并非完全互通"）
- 所以"种割双轨"两条线都跑，得在两个地方分别充值。

**统一管理/打通的两种方式**：
1. **巨量纵横（财务模块）**：超管可在一个后台统一查看 巨量广告/千川/星图 所有账户余额与流水，同主体同组织账户之间还能**转账**（不是一处花两处，是互相调拨）。直客/代理账户均可见自有余额。
2. **共享钱包（2026年7月新功能）**：同一主体下所有账户绑定到一个共享钱包共用资金，减少资金占用（例：10个账户不用各留1万，钱包存5万共用）。⚠️ 需通过**代理商**开通，普通直客可能暂用不上；资金转入记录仅代理商可见。

**实战提醒（重要）**：
- **余额不足会限流（预算平滑）**：账户余额低于消耗需求，系统主动限流避免欠费。规则：建议余额 ≥ 近7天日均消耗的2倍，否则跑量困难。新户跑不动常不是"权重"问题而是钱充太少。
- **充值门槛（参考，以各自后台为准）**：千川直客首充一般5000-10000元(按城市级别)、续充1000起；巨量营销(巨量广告)首充一般500元起。
- **清算时段**：凌晨0-6点系统清算，避免此时段退款。

**落到你**：之前充在巨量营销的钱投不了千川；要用千川卖货，得单独去千川后台「资金管理 → 资金钱包 → 充值」首充激活。两条线预算分开管（见第12节）。

## 17. 蓝V发布视频时如何挂车（前置权限 + 发布操作）

**前置权限（一次性开通，蓝V有零粉丝优势）**：
1. 已入驻**抖音小店**并正常营业（商品上架审核通过）
2. 完成**蓝V企业认证**（蓝V认证后橱窗/带货权限**零粉丝门槛**，不像个人号要1000粉）
3. 缴纳【**商品分享保证金 / 作者保证金**】**500元**（支付宝，区别于店铺保证金；这是拿短视频/直播带货权限的门槛，可退）
4. 抖店商品已上架 → 把商品加入**商品橱窗**（或绑定店铺官方账号后直接从「我的店铺」选）
   - 路径：抖音App → 我 → 商品橱窗 → 添加商品 → 选「我的店铺」/「精选联盟」

**发布视频时挂车步骤（手机端抖音App）**：
1. 点底部「+」发布视频，完成剪辑 + 文案
2. 在发布页找到【**添加标签**】→【**商品**】（或发布页下方「添加商品」按钮，在"谁可以看"上方）
3. 从【我的橱窗】/【我的店铺】勾选已上架商品（单条视频**最多挂5个**，建议主推1-2个）
4. 可设卖点文字（≤15字）、调整商品卡位置
5. 点【发布】→ 视频上线即带**小黄车**（左下角购物车图标），观众点开跳商品详情页

**电脑端发布同理**：抖音创作者服务平台(e.douyin.com) → 内容管理 → 发布视频 → 添加商品。

**⚠️ 关键坑（多次验证）**：
- **视频发布后无法追加挂车！** 挂错/漏挂只能删除重发（星图商单视频同理，发布后不可补挂车）——所以发布前务必确认购物车已挂好
- 商品必须与视频内容**高度相关**，否则影响推荐流量甚至违规
- 直播挂车：开播前/中点击左下角「购物车」图标，从橱窗/店铺加商品，点「讲解」弹商品卡

**和前面章节的衔接**：挂好车的蓝V视频 → 直接在千川「全域推广」拉取主页挂车视频投（见第15节）；未挂车的蓝V种草视频 → 走巨量营销·竞价投（见第11/12节）。挂车状态决定能投哪个平台。

## 18. 达人挂不上你们的商品（个人店限制）+ "加自己店铺"方案不可行

**概念扫盲：个人店 vs 商品橱窗（最易混的两个词）**
- **个人店** = 一种**店铺类型**（用个人身份证开的抖音小店）。你是**商家**：有店铺、上架商品、管库存订单、收货款。
- **商品橱窗** = 抖音号的一个**展示功能 / 货架位**（本身不是店）。任何有带货权限的号都能开，用来把商品（自己店的或精选联盟的）陈列出来，粉丝点视频小黄车 → 跳橱窗 / 商品详情页。
- 两者不是并列关系，是"内容 vs 载体"：开店的人**用橱窗展示自己店货**；纯达人**用橱窗挂别人的货赚佣金**。一个号可同时有「店+橱窗」（商家），也可只有橱窗没店（纯达人）。
- 关键：限制"只能卖本店货"的是**绑了店铺**这件事（人店一体规则），不是橱窗本身。纯达人号的橱窗可挂精选联盟任意商品。

**店铺类型入门（先搞清三种店）**：抖音小店按"经营主体"分三类，门槛和权限递减：
| 类型 | 开店资质 | 能否挂精选联盟（带别人货） | 说明 |
|---|---|---|---|
| **个人店** | 个人身份证，无需营业执照 | ❌ 只能卖本店商品 | 门槛最低，权限最少 |
| **个体店** | 个体工商户营业执照 | ❌ 绑定官方账号后也只能带本店 | 需营业执照 |
| **企业店** | 公司营业执照 | ❌ 同理只能带本店 | 公司主体 |
> 注：以上三种**只要绑定了官方账号/授权号**，现平台规则都只能带本店货；**只有"纯达人号（没绑任何店）"才能自由挂精选联盟分佣带货**。平台推行"人店一体"管理是根源。

**现象**：达人视频挂车时弹窗"个人店暂时仅支持分享推广自己店铺内商品"，添加你们的 SollaWaveAi 失败。

**根因（平台「人店一体」规则）**：
- 达人账号**绑定了个人店**（即官方账号/授权号形态），平台现限制**只能卖本店商品**，不能从精选联盟挂别人家的货。
- 能自由挂精选联盟商品的，只有**纯达人号**（未绑定任何店铺的账号）。
- 绑定了**个人店 / 个体店 / 企业店 / 授权号**的账号，现大概率都只能带本店商品。

**"让她把商品添加到自己店铺再挂车"为何走不通**：
1. **你们不是达人店铺的店主**，无法直接把抖店商品塞进达人的个人店。
2. 即使达人自己在个人店里上架你们的"同名商品"，那是达人以**商家身份自营销售**，不是达人挂精选联盟**分佣带货**——品牌方会失去：CPS 佣金结算、千川托管追投达人挂车视频、「星图/精选联盟」数据回流等协同能力，等于变成经销而非达人种草带货。
3. 个人店经营类目受限，本质也不适合做分销节点。

**可行方案（按优先级）**：
1. **换号（最快）**：让达人用另一个**没绑定店铺的抖音号**发视频挂你们的车（纯达人号最自由）。
2. **关店解绑（根治）**：达人个人店关店后账号自动解绑，恢复纯达人身份，即可挂精选联盟；代价是达人个人店没了。
3. **走非挂车种草（绕开挂车）**：不挂车，用巨量营销·竞价（广告合作码授权）或 DOU+ 代投放大，收割靠用户看后搜 → 千川截流成交。

**合作前置排查（避免拍完才发现挂不上）**：发合作前问达人 3 句——
- 这个号有没有绑店铺？绑的什么类型（个人/个体/企业）？
- 是不是人店一体的官方账号？
- 有没有开个人店？
只要绑了任何店铺，现大概率只能带本店商品，纯达人号才自由挂联盟。
