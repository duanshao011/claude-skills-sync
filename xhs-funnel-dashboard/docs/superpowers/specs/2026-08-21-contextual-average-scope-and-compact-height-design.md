# 全链路表格动态平均值口径与紧凑高度设计

日期：2026-08-21

## 目标

根据全链路表格已确认选择数量动态切换平均值样本，同时收紧固定平均值栏高度。

## 平均值样本规则

- 已确认选择为 0 篇时，标签显示“平均值”，样本为全部 `DATA.notes`。
- 已确认选择为 1 篇时，标签显示“平均值”，样本仍为全部 `DATA.notes`，作为单篇数据的总体对照基线。
- 已确认选择为 2 篇及以上时，标签显示“已选平均”，样本仅包含已确认选择中的笔记。
- 临时勾选不改变平均值样本或标签。
- 点击“确认”后才根据新的已确认选择重新计算。
- 点击外部或按 `Esc` 放弃临时选择时，平均值保持上一次已确认状态。
- 清除选择后恢复全量平均值。
- 其他图表联动单篇到表格时恢复全量平均值。

## 计算与格式

- 数值列计算算术平均。
- 忽略空值、无效值和缺少对应数据源的记录。
- 格式复用正文列规则：整数、比例、小数分别按各自类型显示。
- 固定位置、横向同步、自定义列对齐和冻结列逻辑保持不变。

## 紧凑高度

- 平均值栏字号保持 `13px`。
- 单元格上下内边距从 `7px` 调整为 `2px`。
- 单元格高度调整为约 `26px`，使背景高度接近数字行高。
- 标签保持轻度加粗，数字保持常规字重。

## 验收标准

1. 默认状态标签为“平均值”，内容为全量平均值。
2. 单选一篇并确认后，标签和平均值内容与默认状态一致。
3. 多选两篇并确认后，标签变为“已选平均”，内容按两篇重新计算。
4. 多选临时勾选但未确认时，平均值保持原状态。
5. 点击外部放弃后，平均值保持原状态。
6. 清除选择或外部联动单篇后恢复全量平均值。
7. 平均值栏固定在滚动区域底部，底部位置偏差为 0。
8. 平均值栏实际高度不超过 28px。
9. 横向滚动和冻结列保持对齐。

## 实现范围

- `SKILL.md`：更新动态平均值样本契约与紧凑高度规范。
- `assets/dashboard.js`：根据 `TABLE.selectedIds` 数量选择平均值样本和标签。
- `assets/dashboard.css`：收紧平均值栏内边距与高度。
- `scripts/cdp_check.py`：增加单选、多选、放弃、清除和高度检查。
- `全链路投放看板.html`：备份后覆盖更新。
