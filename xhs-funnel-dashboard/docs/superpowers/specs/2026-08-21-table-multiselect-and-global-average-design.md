# 全链路表格多选与固定总体平均值设计

日期：2026-08-21

## 目标

修正全链路表格平均值口径，并将表格顶部的笔记选择器从单选升级为多选，同时保持其他趋势与成本图表的单篇分析逻辑不变。

## 平均值口径

- 平均值行固定使用 `DATA.notes` 中全部笔记计算。
- 平均值不受表格搜索、多选、排序、分页影响。
- 仅数值列计算算术平均，忽略空值、无效值和缺少对应数据源的记录。
- 显示格式复用正文列格式：整数列显示整数，比例显示百分比，金额、ROI、兑换比等按对应字段格式显示。
- 平均值行继续固定在表格内部底部，并与自定义列、冻结列和横向滚动对齐。

## 表格多选

- 仅全链路表格使用独立的多选下拉组件；其他模块继续使用现有单选组件。
- 下拉列表中每篇笔记前显示复选框。
- 点击选项或复选框可切换选中状态，列表保持展开，允许连续选择多篇。
- 选中多篇后，表格只显示已选笔记；没有选中项时显示全部笔记。
- 选中一篇时，输入框显示 `发布日期 | 笔记ID | 达人昵称`。
- 选中多篇时，输入框显示 `已选 N 篇`。
- 右侧清除按钮一次清空全部选择，并恢复全部笔记。
- 输入关键词仅过滤下拉候选，不直接改变表格结果。
- 当前选中项在搜索其他关键词后仍保留，取消勾选后立即从表格移除。

## 联动规则

- 表格多选不反向同步到趋势分析和成本分析，避免多篇选择覆盖单篇图表状态。
- 其他单篇图表联动到表格时，清空原多选集合，并将该笔记设为唯一选中项。
- 表格联动复选框继续控制是否接受其他模块传来的单篇联动。
- 表格多选状态下，排序、分页和自定义列继续作用于当前选中集合。

## 状态与数据流

- 在 `TABLE` 状态中增加选中笔记 ID 集合，作为表格筛选的唯一多选来源。
- 独立的表格多选组件负责候选过滤、复选框渲染、选中集合更新、输入框摘要和清空操作。
- `renderTable()` 先按选中 ID 集合筛选展示行，再排序和分页。
- `buildAverageRow()` 始终接收全量 `DATA.notes`，不得接收筛选后的表格行。
- 外部联动通过表格组件的单篇替换接口写入唯一 ID，不复用多选点击流程。

## 边界情况

- 搜索无匹配时显示“无匹配笔记”，但不清空已有选择。
- 外部联动的笔记不在当前候选集合时，仍可作为唯一选中项展示，并沿用现有外源笔记提示逻辑。
- 当前选择超过每页行数时正常分页。
- 数据源缺失时仍遵循现有空值和“需上传XX表”规则。

## 验收标准

1. 页面首次打开时表格显示全部笔记，平均值行为全部笔记总体平均值。
2. 勾选两篇笔记后表格仅显示两行，输入框显示“已选 2 篇”。
3. 取消其中一篇后表格仅显示剩余一篇，输入框显示该笔记完整身份。
4. 清空选择后恢复全部笔记。
5. 多选前后平均值行数值保持不变。
6. 从趋势或成本图表联动一篇笔记后，表格原多选被替换为该单篇。
7. 表格多选不会改变趋势和成本图表当前选中的笔记。
8. 平均值行列数始终与当前表头一致，横向滚动和冻结列正常。
9. 原有总 GMV、整体 ROI、数据源状态、排序、分页和自定义列验证继续通过。

- `assets/dashboard.css`：复选框、选中态和输入摘要样式。
- `scripts/cdp_check.py`：增加总体平均值、多选、清空和外部替换验证。
- `全链路投放看板.html`：备份后由现有构建脚本覆盖更新。
