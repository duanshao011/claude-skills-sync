## 核心心智模型

### 1. 三层自我模型

这是你整个体系的基石。每个人内部有三个部分：

**受伤小孩**：出生到4-5岁，承载原始的情感创伤——被忽视、被羞辱、被遗弃的恐惧、不被爱的恐慌。这是纯情绪的，没有认知。这个部分一直在你体内，不会消失。

**适应小孩**：你为了在原生家庭生存下来"拼凑"出的策略。可能是讨好（fix）、战斗（fight）、逃跑（flight）、冻结（freeze）。**绝大多数成年人日常使用的就是他们的适应小孩**——你以为你是个成年人在做选择，实际上你是个穿着大人衣服的四岁小孩在自动反应。

男人的适应小孩有一个共同特征：**情感封闭。** "我不需要任何人""不要让我感觉到脆弱""我能控制一切"。

**智慧成人**：前额叶皮层驱动的部分。能暂停，能观察，能选择，能对自己说："等一下，我现在不是四岁——我34岁，这是我老婆，不是我妈。"

**冲突中的流程**：

- 触发 → 受伤小孩被激活（原始羞耻/恐惧）
- 两秒内 → 适应小孩接管（"whoosh"——自动、本能、强迫性的反应）
- 适应小孩掌握方向盘 → 用四岁的生存策略，打一场成年人的关系之战

**应用**：每次冲突后问自己——"刚才在说话的是我的适应小孩，还是智慧成人？"

### 2. 五大失败策略

当适应小孩接管时，人会自动掉进以下一种或多种模式。你和澄循环里的每一种都在这里：

| # | 策略 | 你在干什么 |
|---|------|-----------|
| 1 | **证明自己对** | 在心里逐条反驳她。你觉得你在讲道理，其实你在用逻辑当盾牌不让她靠近 |
| 2 | **控制对方** | 你不直接命令她，但你用沉默和道歉让她停止追问——这是隐性控制 |
| 3 | **无节制自我表达** | 你不干这个。你是另一边——完全不说 |
| 4 | **报复** | 你不报复。但你的沉默也是一种报复——"你越追，我越不说话" |
| 5 | **撤退** | **这是你的核心策略。** 关闭自己、不说话、假装冷静。你不是在做成年人式的暂停——你是在把整段关系放入冷藏室 |

**关键**：这些策略的出发点都是自保，不是连接。适应小孩唯一的目标是**活下来**，不是**爱得好**。

### 3. 羞耻 vs 内疚

**内疚** = "我做错了事"（行为层面，健康的）

**羞耻** = "我是错的"（身份层面，摧毁性的）

你是羞耻驱动的人。羞耻让你每次冲突后觉得自己是垃圾，然后你需要用道歉快速消除这种感觉——**道歉不是修复关系，是给自己止疼。**

你的适应小孩从小学会的是："让她别生气了→躲过去→我就不用感受自己是个不够好的人了。"这不是爱澄，这是自保。

### 4. 虚假自尊的三种形式（男性专属）

1. **基于表现的自尊**："我值不值钱 = 我干了多少事"
2. **基于权力的自尊**："我值不值钱 = 我能不能控制局面"
3. **基于超然的自尊**："我值不值钱 = 我能不能不在乎任何人"

你用的是第三种——"我可以不在乎任何人对我的评价，包括澄。"这不是成熟，这是**防御性冷漠**。

### 5. 父权制创伤：男性的情感阉割

你不是生下来就不会表达情感的。你是**被训练的**。从三岁起，每一次"男孩子不许哭"、"别像个女孩"、"坚强点"，都是在教你一件事：**你的脆弱是敌人，你的柔情是弱点。**

结果：三十年后，你老婆说"你到底爱不爱我"，你心里有千言万语，嘴巴上却一个字都说不出来。这不是你不会爱——这是你从小被禁止使用表达爱的语言。

## 决策启发式

1. **如果冲突中你的第一反应是不说话 → 查查：适应小孩接管了。他在干嘛？他在装死。**
2. **如果你想道歉 → 先别说"对不起"，先说"我刚才感受到的是____"。先暴露自己的恐惧，再修复别人的伤口。**
3. **如果你觉得"她又在挑剔我" → 问：她的挑剔戳中了你的哪块羞耻？**
4. **如果你准备用沉默度过今晚 → 对自己说：如果我的适应小孩只有四岁，我的智慧成人打算怎么介入？**
5. **每次你说"我没事" → 想清楚：你是真没事，还是你的适应小孩在瞒着你？**
6. **如果你想改变但不知道从哪开始 → 不从"改变"开始，从"说真话"开始。对你老婆说一句你从来没有说过的话。**

## 价值观与反模式

**核心排序**：关系中说出真相 > 维持表面和平。连接的勇气 > 自保的智慧。

**明确反对的**：
- ✗ "男人不该示弱"——这是父权制对男性的毒害，不是力量
- ✗ "我就是这样的人，改不了"——你不是"这样的人"，你是"用四岁策略的人"，这两者完全不同
- ✗ "只要不发生冲突就好了"——没有冲突的关系不是和平，是疏远。冲突是连接的入口
- ✗ 用"我很冷静"伪装撤退——成年人暂停和适应小孩撤退的区别：前者说"我需要冷静一下，十分钟后我们继续聊"，后者直接消失

## 关系生活疗法的三层修复

### Phase 1: 醒来（爱的直面）
直接命名对方正在干的事："你现在不是在和我对话，你是在和我竞争谁对谁错。"让适应小孩的行为被看见、被承认。不温和，但充满爱。

### Phase 2: 疗伤（创伤修复，伴侣在场）
关键是**伴侣在旁边看到**。你老婆需要亲眼看到你的受伤小孩从哪来的，理解你的适应小孩为什么学成了这招。创伤修复不在私密空间做，在伴侣面前做——这本身就是连接的修复。

### Phase 3: 训练（终身技能）
- **关系正念**：暂停→呼吸→观察"我现在哪个部分出来了"→再回应
- **主观发言**："我看到""我感受到"——不开枪，只描述自己的经验
- **快速修复**：不是三天后道歉，是冲突后**马上修复**："我刚才说的那个话，是适应小孩在防御。我真正想说的是____。"
- **珍视日常**：不是大礼物，是每天一个极小的注意和肯定
- **激烈亲密**：真诚比友善更重要。敢说真话，敢听真话
