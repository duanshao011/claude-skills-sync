# 95提问法

> 在你不知道自己不知道什么时，别让 AI 直接给答案。先帮我把问题问清楚。

## 你什么时候需要它？

- **面临重要选择却说不清自己要什么**——"要不要离职""该不该转行""两个方向怎么选"
- **有个模糊的想法但不知道怎么推进**——"我想做内容创业""想优化团队效率"
- **已经被多个选项困住，越分析越乱**——每个选项都有利弊，缺一个帮你理清的人

如果你只是问一个事实（"Python 和 JavaScript 哪个更快"），不需要这个 skill。如果你在做一个**后果严重、信息不完整**的决策，装上它。

## 它会交付什么？

不是结构化报告，不是 SWOT 分析表。是一次深度对话——AI 会像一个敏锐的朋友，一次只问一个问题，直到理解了你的真实处境，再告诉你：

- 你的情况到底是什么（用你自己的话重述）
- 关键约束是什么
- 可行的路径有哪些，各自的代价
- 如果方向已经清楚，接下来该做什么
- 如果有明显更好的选项，直接说，不给模棱两可的建议

## 快速开始

放到 `~/.claude/skills/` 目录下：

```
~/.claude/skills/95提问法/
  SKILL.md
  README.md
  references/
    full-instructions.md
  test-prompts.json
```

重启 Claude Code 或刷新 skill 面板即可。

## 触发方式

直接说这些话就能触发：

- "怎么办，我纠结要不要..."
- "帮我分析一下，我现在..."
- "不知道该不该..."
- "两个方向怎么选..."
- "帮我想想..."
- "我有个问题，迷茫..."

不需要说 `/95提问法` 或 "启动95提问"。像平时聊天一样开口就行。

## 示例

**用户**：「我在想要不要离开现在的公司，纠结好几个月了」

**AI**：「你纠结的点主要是哪个——是现在的工作本身让你不舒服，还是有别的机会在拉你？」

**用户**：「其实有个机会，前同事拉我一起创业，但我不确定这个方向靠不靠谱」

**AI**：「他们做的方向你了解多少？你有没有自己调研过？」

...（持续追问 4-5 轮后）

**AI**：「所以你的情况是——现在的公司没有成长空间，创业机会的方向你调研后发现用户需求是真的，但你最担心的是家庭收入稳定性。三个可行的路：立刻走全力创业、跟同事谈兼职试水 3 个月、换一家公司边上班边观望。基于你说了'最不能让步的是家庭稳定'，兼职试水可能最适合你现在的情况。具体来说你需要做这几件事：...」

## 它和同类有什么不同？

| | 95提问法 | grill-me | askFirst | Interview Me |
|---|---|---|---|---|
| 场景 | 生活/商业/职业决策 | 代码架构决策 | 技术需求分析 | 产品需求澄清 |
| 语言 | 中文优先 | 英文 | 中文 | 英文 |
| 输出 | 自然决策对话 | 计划压力测试 | 技术方案 | 结构化需求文档 |
| 生态联动 | 可切专家团多视角 | 独立使用 | 独立使用 | 独立使用 |

## 安全边界

- **不会替你操作任何东西**——只提问、只分析、不执行
- **会主动停止**——连续两轮没挖出新信息就停；你喊停就停
- **不延伸无关话题**——追问只围绕你的决策，不做知识性发散
- **不暴露内部流程**——你不会看到"信息缺口扫描""95%阈值"这类术语
- **紧急情况会加速**——你说"现在就要决定"，自动缩短到 1-2 轮追问
