# 95提问法

> 在你不知道自己不知道什么时，别让 AI 直接给答案。先帮我把问题问清楚。

## 你什么时候需要它？

- **面临重要选择却说不清自己要什么**——"要不要离职""该不该转行""两个方向怎么选"
- **有个模糊的想法但不知道怎么推进**——"我想做内容创业""想优化团队效率"
- **已经被多个选项困住，越分析越乱**——每个选项都有利弊，缺一个帮你理清的人

如果你只是问一个事实（"Python 和 JavaScript 哪个更快"），不需要这个 skill。如果你在做一个**后果严重、信息不完整**的决策，装上它。

## 它会交付什么？

不是结构化报告，不是 SWOT 分析表。是一次深度对话：

1. **先了解你**——读取你的知识库和历史记录，不重复问你已经想过的东西
2. **给你一张追问地图**——告诉你这个问题涉及哪几个方面、大概要聊几个问题，问你有没有补充
3. **逐轮追问**——一次只问一个问题，每个问题告诉你为什么要问、会怎么影响方案方向
4. **边问边校准**——发现你的回答有模糊、矛盾或偏离主线的地方，会及时帮你理清
5. **给出基于你真实处境的方案**——每个建议都锚定在你的具体条件上，第一步是你明天就能做的动作
6. **压力测试方案**——主动帮你找方案的漏洞：什么情况下会失效、你觉得最大的障碍是什么

## 快速开始

放到 `~/.claude/skills/` 目录下：

```
~/.claude/skills/95提问法/
  SKILL.md
  README.md
  references/
    full-instructions.md
  test-prompts.json
```

重启 Claude Code 或刷新 skill 面板即可。

## 触发方式

直接说这些话就能触发：

- "怎么办，我纠结要不要..."
- "帮我分析一下，我现在..."
- "不知道该不该..."
- "两个方向怎么选..."
- "帮我想想..."
- "我有个问题，迷茫..."

不需要说 `/95提问法` 或 "启动95提问"。像平时聊天一样开口就行。

## 示例

**用户**：「我在想要不要离开现在的公司，纠结好几个月了」

**AI**：「这个问题可能涉及几个方面——当前工作的瓶颈在哪、离开后的方向是否明确、家庭和经济上的承受力。大概需要4-5个问题来聊清楚，不过聊的过程中如果发现新的关键方向会补充。你觉得还有没有我没想到的？」

**用户**：「差不多，主要是有个创业机会在拉我」

**AI**：「那这个创业机会你自己调研过吗，还是主要听对方介绍的？——因为这会决定你后面的判断是基于一手信息还是二手信息，方案方向会不一样。」

...（持续追问，每2-3轮做阶段性小结，确认优先级排序后收敛）

**AI**：「你的情况是——现在的公司没有成长空间，创业方向你调研后发现需求是真的，但最担心家庭收入稳定性。基于你说'最不能让步的是家庭稳定'，兼职试水3个月最适合你现在。第一步：明天晚上花1小时，把创业方向的3个核心假设列出来，和你前同事逐个确认……这个方案最可能失效的点是——试水期你的精力被本职工作占满，3个月到了什么都没验证。你觉得这个风险你能怎么应对？」

## 安全边界

- **不会替你操作任何东西**——只提问、只分析、不执行
- **会主动停止**——方案收敛就停；你喊停就停；硬上限7轮追问
- **不延伸无关话题**——追问只围绕你的决策，跑偏了会主动拉回来
- **不暴露内部流程**——你不会看到"信息缺口扫描""95%阈值"这类术语
- **紧急情况会加速**——你说"现在就要决定"，自动缩短到1-2轮追问
- **已做过充分调研**——识别后跳过信息补全，直接进入校准和分析
