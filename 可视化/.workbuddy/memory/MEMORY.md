# 可视化 Skill 项目约定

- 页面功能由三大模块组成：知识学习（输入源→自动整理→结构化+分类管理）、学习检测（提炼知识点→问答自测）、问题本（实时记录问题→一键整理+序号）。
- 划线交互重新开发，保留“有问题、记一下、准备使用”三个动作；“有问题”自动进问题本，问题只分待解决/已解决，不能靠删除表示掌握。
- 学习检测默认只生成解释、辨析、迁移三道核心题；仅在答错、暴露真实问题或存在多个独立核心模块时追加针对题。
- 前端采用博哥给定的设计系统：:root 主题变量、毛玻璃 sticky 导航+滚动进度条、两栏 grid（sticky 目录 scroll-spy + 正文）、Hero 首屏、组件库按需灵活组合（卡片/特性卡/标签卡/公式卡/表格/分层/流程/Callout/误区卡/清单卡）。页面整体浅色；深色仅允许用于公式卡、表头等局部语义组件，不得做全局暗色主题。
- 信息源分两条路径：文本/文档等走 content 模式（AI 整理 + 设计系统骨架）；已生成 HTML 走 passthrough 模式（保留原页面前端展示/样式/内容，仅剥离 script 防冲突，叠加工具栏 + 检测/问题本侧滑面板 + 划线 + 数据面板）。
- 产物为单一自包含离线 HTML，无 CDN/远程脚本/远程字体；必须完整实现 pageId 隔离、localStorage 持久化+备份、稳定 ID、JSON 导入导出、旧 errbook_highlights 迁移、阅读位置恢复、当前页重置。
- ⚠️ 惨痛教训：skill 目录（assets/、outputs/、SKILL.md 等）曾全部丢失，只剩空目录。后续重要工作要本地备份 + 通过 COSBrowser/OSS 同步，避免仅依赖单一路径。
