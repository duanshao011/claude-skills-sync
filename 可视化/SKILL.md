# 可视化 Skill

将知识内容转化为结构化的可视化 HTML 学习页面。

## 核心原则

**目的**：帮用户更高效地理解和内化知识。图表和文字是互补关系——图表展示结构/关系/量级，文字保留细节和 nuance。图表不替代文字。

**红线**：
- 禁止在没有原文数据依据的情况下，在 SVG 图表中填入具体数值
- 如果原文只有定性描述（如"流量大幅衰减"），图表只能展示结构，数值标注"示意"
- 精确数据（原文有明确数字）和示意数据（仅展示结构关系）必须区分标注

---

## 工作流程（5 步）

### Step 1: 提取结构化数据清单

阅读用户提供的知识内容，输出一份结构化数据提取表给用户确认。

数据提取表格式：

```markdown
## 结构化数据提取

### 精确数据（原文有明确数值）
| 数据点 | 数值 | 出处（原文原句） |
|--------|------|-------------------|
| 代理商返点 | 18% | "充10万，目前代理商给我们返18个点" |
| 薯条阅读成本 | 0.02-0.04元 | "阅读的成本基本都是4分钱左右" |

### 关系/结构（可用于图表骨架）
| 关系描述 | 类型 | 出处 |
|----------|------|------|
| 曝光→点击→进店→加购→成交 | 5层漏斗 | "最前端有个叫曝光。曝光过来是点击…" |
| A→I→T 人群分层 | 3层金字塔 | "人群资产。资产就是A，I，T" |

### 对比关系（可用于对比图表）
| 对比维度 | A | B | 出处 |
|----------|---|---|------|
| 流量成本 | 薯条 0.02-0.04/阅读 | 聚光 0.6-2.0/点击 | 多条原文 |
```

**⚠️ 这一步不能跳过。用户确认数据清单后再进入 Step 2。**

### Step 2: 规划可视化映射

根据确认后的数据清单，决定哪些内容用图表、哪些保留纯文字。

使用以下决策矩阵：

| 原文特征 | 推荐可视化 | 不推荐 |
|----------|-----------|--------|
| 有层级/包含关系 | 金字塔图、树形图 | — |
| 有逐层递减的流程 | SVG 漏斗图 | 横向 flow（看不出量级差） |
| 有 A vs B 多维对比 | 对比卡片、柱状图、雷达图 | 纯文字段落 |
| 有资金/权力/信息流向 | SVG 流向图（节点+箭头） | 纯文字描述 |
| 有数据量级差异（>10倍） | 柱状对比图、大号数字卡片 | 表格（差异不够直观） |
| 有步骤/阶段/时间线 | process 列表、泳道图 | — |
| 纯操作列表/清单 | **保留纯文字 process** | 强行画图反而降低效率 |
| 纯定义/概念说明 | **保留纯文字 + quote** | 图表没有增值 |

### Step 3: 生成 HTML

基于 `assets/template.html` 构建。模板包含：

**已有组件（纯文字）**：
- section / h2+h3 / info-card / data-table / compare-grid
- flow / process / quote / badge / tag / unclear-block

**新增 SVG 图表组件**：
- **漏斗图 (funnel-chart)** — 逐层收窄的梯形，每层标注指标+数值
- **金字塔图 (pyramid-chart)** — 三层或更多层的三角形堆叠
- **对比卡片 (compare-cards)** — 左右对称卡片 + 中间 VS 分隔，关键数字放大
- **流向图 (flow-diagram)** — 矩形节点 + 箭头连线，区分实线（指标流）和虚线（资金流）
- **柱状对比 (bar-compare)** — 横向/纵向柱状，用于数值差异大的对比

**每个图表必须附带「📋 数据溯源」面板**（可折叠），格式：
- 三列表格：图表元素 → 来源标注 → 原文引用
- 原文引用从数据提取表中直接取，不二次归纳

**数据标注规范**：
- 精确数据用 `.data-exact` 标签（绿色小标）：标注"原文数据"
- 示意数据用 `.data-illustrative` 标签（灰色小标）：标注"仅示意结构"

### Step 4: 自检验证

生成完成后，逐项检查：

- [ ] 每个 SVG 图表中的数值，在溯源面板中都有对应的原文引用
- [ ] 没有凭空编造的数字（如原文无数据，图表只用结构不用数值）
- [ ] 示意数据和精确数据有视觉区分
- [ ] 每个图表都可以在溯源面板中找到出处
- [ ] 图表文字可被划线系统选中（SVG 内联 text 元素可行）
- [ ] 移动端响应式正常（768px 断点）

### Step 5: 输出

将完整 HTML 保存到用户指定位置（默认桌面），告知用户：
- 用浏览器打开即可使用
- 划线备注和错题本功能
- 每个图表下方的「📋 数据溯源」面板可展开验证

## 页面组件库

### 基础布局
- **page-layout** — 页面最外层 flex 容器，包含左侧目录 + 右侧主内容
- **toc-sidebar** — 左侧目录导航栏，JS 自动从 section h2/h3 生成，滚动时高亮当前位置，移动端收起为侧滑抽屉
- **section** — 每个独立主题用一个 `.section` 卡片包裹，`h2` 标题前加 `.num` 序号
- **h3 子标题** — 橙色左边框，用于板块内子主题
- **h4 子标题** — 用于更细粒度的分组

### 信息展示
- **info-card** — 指标卡，含 `.card-label`（标签）、`.card-value`（数值）、`.card-desc`（说明），用 `.info-grid` 网格排列
- **data-table** — 数据对比表，`th` 表头灰底
- **compare-grid** — 两栏对比布局，`.compare-col` 左/右列

### 流程与步骤
- **flow** — 横向流程图，`.flow-step` 节点 + `.flow-arrow` 箭头（→）
- **process** — 纵向步骤列表，CSS 自动编号

### 引用与标注
- **quote** — 紫色左边框引用块，用于原文摘录
- **badge** — 小标签，绿/红/蓝/黄四色（`.badge-green` / `.badge-red` / `.badge-blue` / `.badge-yellow`）
- **num-highlight** — 数字高亮（橙色加粗）
- **unclear-block** — 黄色虚线框，标注不确定的概念
- **data-exact** — 精确数据标签（绿色小标），标注"原文数据"
- **data-illustrative** — 示意数据标签（灰色小标），标注"仅示意结构"

### SVG 图表
- **funnel-chart** — SVG 漏斗图，逐层收窄梯形，每层标注指标+数值
- **pyramid-chart** — SVG 金字塔图，三角形分层，底层最宽顶层最窄
- **compare-cards** — 对比卡片组，`.viz-cards` 容器 + `.viz-card` 卡片 + `.vs-divider` VS 分隔
- **flow-diagram** — SVG 流向图，矩形节点+箭头连线，实线=指标流/虚线=资金流
- **bar-compare** — SVG 柱状对比，横向或纵向
- **viz-callout** — 图表下方数据标注卡片组，`.viz-callout` + `.viz-callout-item`

### 数据溯源（每个图表必须附带）
- **trace-panel** — 可折叠溯源面板，包含 `.trace-toggle`（折叠按钮）+ `.trace-body`（溯源内容） + `.trace-table`（三列对照表：图表元素/来源/原文引用）

### 其他
- **tag** — 圆角标签，用 `.tag-row` 包裹
- **hr** — 分隔线
- **legend** — 图例条

## HTML 模板

使用 `assets/template.html` — 这是完整的页面框架，包含：

1. **CSS 设计系统** — 浅色主题，CSS 变量驱动，响应式。额外变量：`--accent-light`, `--blue-light`, `--green-light`, `--red-light`, `--yellow-light`, `--purple-light`（用于淡色背景）
2. **左侧目录导航** — 自动从 section h2/h3 生成，sticky 定位，滚动高亮，移动端为侧滑抽屉
3. **划线备注系统** — 鼠标划选文字 → 弹出「💡 记一笔」→ 橙色波浪下划线标记
4. **错题本** — 右下角 📋 浮动按钮 → 侧边面板展示所有划线记录（含上下文、跳转原文、删除）
5. **数据持久化** — localStorage 存储划线备注
6. **SVG 图表组件 CSS** — 漏斗图、金字塔图、对比卡片、流向图、溯源面板的完整样式
7. **溯源面板模板** — 可折叠的三列对照表，内置 CSS 和交互逻辑

### 模板占位区域

- `<!-- TITLE -->` → 页面标题
- `<!-- HEADER_PLACEHOLDER -->` → 页面头部（标题、来源标签）
- `<!-- CONTENT_PLACEHOLDER -->` → 所有 section 板块
- `<!-- FOOTNOTE_PLACEHOLDER -->` → 页脚（来源和整理说明）

## 内容组织原则

- **穷尽但不重复** — 同一信息不跨板块重复
- **基于原文** — 不添油加醋，不编造原文没有的内容。所有数据点必须可追溯到原文
- **颗粒度匹配原文** — 不删减原文覆盖的要点
- **概念存疑标注** — 遇到无法确定含义的术语，用 `.unclear-block` 标注出来
- **图表辅助文字** — 图表展示关系和结构，文字保留细节。两者共存，不相互替代
- **精确 vs 示意严格区分** — 精确数据标注"原文数据"，示意数据标注"仅示意结构"
- **中文优先** — 标题、标签用中文，CSS 类名保持英文

---

## 注意事项

- 输出文件必须是完整的、可独立打开的 HTML（不依赖外部资源）
- 模板中的 JS 划线系统和错题本**不要修改**，直接保留
- 页面默认浅色主题，CSS 变量集中在 `:root` 中，如需调色只改变量值
- SVG 图表配色只用 CSS 变量（`var(--accent)`, `var(--blue)` 等），不硬编码颜色
- SVG 中的 text 元素可被划线系统选中（使用内联 `<text>` 标签而非 `<path>` 文字）
- 溯源面板的原文引用必须为原文原句，不做二次归纳
- 生成完必须执行 Step 4 自检验证
