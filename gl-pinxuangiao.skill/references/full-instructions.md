# 光粒品宣稿 Skill

## 使用前提

用户提出撰写品宣类笔记/稿件需求时触发。**写之前必须确认素材齐全，信息不全不动笔。**

## 使用前准备

1. 读取产品知识库：`C:/Users/duansb/.claude/skills/gl-shenhe.skill/product-knowledge.md`（共享，确保产品参数准确）
2. 识别稿件类型（type-1 / type-2 / type-3），不确定时向用户确认
3. 按对应类型的信息清单核对素材，缺失项列出后让用户补充

| type-3 铁三预热 | 铁三赛事前后宣传 | 铁三/广德/赛事/预热/预告/赛场/现场 |

## 二、共用规范

### 发布平台与字数

| 平台 | 字数 | 风格 |
|------|------|------|
| 公众号 | 700-800 字 | 叙事长文，有故事感，克制有分量 |
| 小红书 | 250-350 字 | emoji 节奏，短句分行，通俗不随意 |

> 字数统计方式：含中文、英文、数字、标点在内的总字符数（Word/WPS "字数"口径）。

### 通用写作原则

1. **场景切入**：每篇必有具体画面/事件做"新闻钩子"，不凭空起笔
2. **故事先行**：事件/人物比产品功能更有吸引力，用人/事带产品
3. **数据说话**：成绩、时间、数字精确引用，不模糊处理
4. **产品克制**：功能只提核心 1-2 点，说定位+核心价值，不堆砌术语不展开参数
5. **金句贯穿**：两篇共用一句核心金句，形成记忆锚点
6. **三篇一致性**：同类稿件的标题格式、结构、调性保持统一

### 固定 Hashtag

发布标签统一从产品知识库获取：`C:/Users/duansb/.claude/skills/gl-shenhe.skill/product-knowledge.md` → "六、发布通用标签"章节。

按产品线选择对应标签，不要自行编造。特殊活动场景（如铁三赛事）用户可能指定专属 tag，以用户最新要求为准。

> 铁三赛事专属标签（仅铁三相关稿件使用）：
> `#光粒铁三瞬间 #告别鳄鱼眼用Holoswim3Pro游直线 #光粒科技 #Holoswim3ProAR智能泳镜`

### 产品提及原则

- 只说：产品名 + 定位（一句话）+ 核心功能（1-2 句话）
- 不说：详细参数、技术术语堆砌、竞品对比
- 绑定方式：从运动员痛点/活动场景自然过渡，不做硬广

## 三、type-1 品宣活动

### 信息清单

| 信息项 | 说明 |
|------|------|
| 活动名称/类型 | 展会/品牌合作/线下入驻等 |
| 活动时间地点 | 具体日期、城市、场馆 |
| 活动亮点 | 展出产品、体验环节、互动福利 |

| 合作方信息 | 合作品牌/展会/渠道的基本信息 |
| 主推产品 | 活动重点展示的产品名+定位 |

### 公众号结构

```
标题：光粒 × [活动/合作方] | [事件核心钩子]
开篇：活动现场画面/布展场景 → 事件说明 → 品牌价值
中段：活动亮点展开（展品/体验/互动）→ 产品自然带入
结尾：活动信息 + 品牌愿景收束
【图片占位 ×1】
```

### 小红书结构

```
标题：光粒 × [活动/合作方] + emoji
开篇：事件一句话官宣
中段：3-4 个亮点 bullet list（emoji 编号）
产品：一句话绑定
结尾：互动邀约 + hashtag
【图片占位 ×1】
```

## 四、type-2 品牌大使

### 信息清单

| 信息项 | 说明 |
|------|------|
| 运动员基本信息 | 姓名、年龄、外号/标签、身份（协会/俱乐部职务等） |
| 个人背景故事 | 入坑起点（时间+原因）、反差/转折点（如跨界、草根逆袭） |
| 核心战绩 | 按时间线排列的主要比赛成绩，含具体数字 |
| 个人训练理念/标签 | 如"科学训练""长线稳定""数据控" |
| 与品牌契合点 | 品牌故事 × 个人故事的共同叙事线 |
| 最近一场赛事 | 用作开篇"新闻钩子"，增强时效感 |
| 其他大使信息 | 同级别大使姓名，用于"与 XX、XX 共同组成战队" |
| 品牌信息 | 品牌名、主推产品名、产品定位（一句话）、核心功能（1-2 句）|

### 公众号结构

```
标题格式：光粒品牌大使 | 姓名：前半段身份标签 + 后半段反差/成就钩子

开篇：
  - 最近一场比赛画面切入（时间+成绩+画面感）
  - 正式官宣签约消息（"XX 出任光粒品牌大使，与 XX、XX 一同……"）
  - 价值共鸣（品牌与个人的"平凡者"共同叙事）

中段·深度故事：
  - 从起点讲起（时间+原因+最初的朴素动机）
  - 以时间线串联关键成绩递进（数字精确）
  - 落脚到训练理念/方法论（不要只罗列成绩）
  - 一句金句收束

中段·产品绑定：
  - 从运动员痛点/理念自然过渡到产品
  - 产品定位+核心价值（1-2 句），不做功能罗列
  - 品牌技术实力一句话带过

结尾：
  - 金句呼应
  - 品牌愿景（"未来，光粒将与 XX 一起……"）
  - 图片占位 ×1
```

### 小红书结构

```
标题格式：光粒品牌大使 × 身份标签 + 姓名 + emoji

开篇：
  - 官宣一句话 ✅
  - 最近战绩一句话 🔥

反差钩子：
  - "但你可能想不到，他的起点——"
  - 背景故事 2-3 句

成绩 bullet list：
  ▪️ 成绩1
  ▪️ 成绩2
  ▪️ 成绩3
  ▪️ 成绩4

训练理念：
  - 一句话总结方法论

产品绑定：
  - 一句产品定位 + 一句与运动员的契合点 🤝

金句收尾 ✨

【图片占位 ×1】

固定 hashtag
```

## 四-b、type-2b 赛事成绩宣发

> 品牌大使参加铁三赛事后，基于比赛成绩进行品牌官号宣发。核心目的：用运动员的真实战绩反复强化"光粒 = 专业铁三装备"的认知。

### 信息分级

#### 必填项（缺任一项不动笔）

| 信息项 | 说明 |
|------|------|
| 运动员姓名 | 全名，需与品牌大使库一致 |
| 赛事名称 | 完整赛事名，如"2026 IRONMAN 岘港 70.3" |
| 成绩/名次 | 总完赛时间 + 名次/组别排名 |

#### 选填项（有就用，没有跳过）

| 信息项 | 说明 |
|------|------|
| 分段成绩 | swim / bike / run 各段用时 |
| 赛道/天气/环境 | 温度、爬升、海况、赛道特点等 |
| 比赛关键时刻 | 某一赛段的策略、逆袭、冲刺等具体细节 |
| 运动员赛后原话 | 赛后采访或朋友圈的真实表达 |
| 历史战绩 | 连续 X 场领奖台、PB 提升幅度等纵向数据 |
| 下一场赛事 | 赛事名称+时间，用于结尾展望 |

### 两档判定

- **精细版**：选填项 ≥ 3 项 → 内容有场景、有故事、有数据纵深
- **通稿版**：选填项 < 3 项 → 简洁战报，不硬凑细节

### 公众号结构

#### 精细版（700-800 字）

```
标题：光粒品牌大使 [姓名] | [赛事名] + [成绩亮点]

① 成绩速报（1-2 句）
  - 赛事名 + 名次 + 总成绩
  - 分段成绩列出（swim / bike / run）

② 赛道场景（2-3 句）
  - 天气、赛道特点、难度，建立现场画面感

③ 比赛关键时刻（3-5 句）
  - 聚焦 1-2 个赛段的具体表现（策略、节奏、逆风、冲刺）
  - 不写流水账，只写有张力的节点

④ 产品自然露出（1 句）
  - 仅在游泳段提及，如"佩戴 Holoswim XX 实时掌握配速数据"

⑤ 运动员原话收尾（1-2 句）
  - 用运动员自己的赛后感受收束，比品牌自己说更有力

⑥ 展望（可选，有下一场赛事信息时加）
```

#### 通稿版（500-600 字）

```
标题：光粒品牌大使 [姓名] | [赛事名] + [成绩亮点]

① 成绩 + 赛事（2-3 句）
  - 赛事名 + 名次 + 总成绩，一句话交代清楚

② 竞技状态概括（2-3 句）
  - 基于成绩本身做客观评价，禁止空洞夸赞
  - 可结合历史战绩做纵向对比（如有）

③ 产品露出（1 句）
  - 同精细版，一句带过

④ 收尾（1-2 句）
  - 有下一场信息 → 展望下一站
  - 无下一场信息 → 品牌陪伴一句话收束，不堆砌
```

### 小红书结构

#### 精细版（300-350 字）

```
标题：[成绩数据] + [姓名] + [赛事名] + [成绩亮点关键词]
  例：4:15:42 分龄组冠军！曹俊宇 IRONMAN 岘港 70.3 再夺冠

🏊 游泳 XX:XX | 🚴 骑行 X:XX:XX | 🏃 跑步 X:XX:XX
总成绩 X:XX:XX，[组别] [名次]。

比赛亮点 1-2 句（赛道/天气/关键赛段）

历史纵向（可选）：从 [上一场] 到 [这一场]，连续 X 场领奖台

产品一句：游泳段全程佩戴 [产品名]

"[运动员赛后原话]"

📍下一站：[赛事信息]（可选）

互动引导（问句收尾）

固定 hashtag
```

#### 通稿版（250-300 字）

```
标题：[姓名] [赛事名] [成绩亮点] + emoji
  例：曹俊宇 IRONMAN 岘港 70.3 分龄组冠军🏆

[赛事名]，[姓名] 以 [成绩] 拿下 [名次]。

竞技状态 1 句（客观评价，不空洞）

产品一句：游泳段全程佩戴 [产品名]

互动引导（问句收尾）

固定 hashtag
```

### 专属写作原则

1. **成绩先行，品牌后置**：用户来看战报不是看广告，产品露出控制在全文 10% 以内
2. **数据精确**：完赛时间、分段成绩、排名是铁三圈的硬通货，有就必须列，不模糊不四舍五入
3. **一篇一人一赛**：不合并写多人或多场，会稀释故事感
4. **不硬凑细节**：信息不够就走通稿版，宁可简洁也不编造场景
5. **禁用套话清单**（以下表达直接禁止）：
   - "始终保持高质量竞技状态"
   - "日复一日的系统训练"
   - "拼的不只是速度，更是……"
   - "以专业智能运动装备，陪伴他奔赴更多赛道"
   - 任何可以把运动员名字替换成别人仍然成立的泛化夸赞

```
标题：赛事名称 + 品牌活动钩子 + emoji
开篇：赛事临近氛围 1-2 句
活动介绍：bullet list（emoji 编号）

结尾：参与引导 + 赛事祝福 + hashtag
```

## 六、输出流程

1. **核对信息** — 按类型清单检查，缺失项列出让用户补充。type-2b 额外判档：统计选填项数量，≥ 3 走精细版，< 3 走通稿版，告知用户当前判定结果
2. **先写公众号** — 用户确认文风/结构/字数
3. **再写小红书** — 用户确认
4. **按需生成 docx** — 用户明确说"生成 docx/wps"时才生成，不主动生成

---

## 七、注意事项

- 信息不全不动笔，先列缺失项和用户确认
- 产品内容始终克制，品宣稿的核心是"事/人"不是产品说明书
- 数据、时间、成绩必须精确，不模糊不约等于
- 三类型稿件的输出格式、金句、调性保持一致
- 可引用产品知识库中的"说人话表达"，拒绝说明书腔
- 不夸大、不贬低竞品、不说绝对化用语
- type-2 和 type-3 如涉及同一赛事，注意信息互通不矛盾
- type-2b 与 type-3 如涉及同一赛事，成绩数据必须一致
