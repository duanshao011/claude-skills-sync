# 品宣稿参考案例库

> 每个案例包含：来源信息、原文摘要、结构拆解、可借鉴点、需规避点。

## 案例 001：Rokid × 央视世界杯官宣稿

- **来源**：公众号「Rokid乐奇」
- **标题**：乐奇Rokid携手中央广播电视总台，达成顶级赛事AI眼镜独家合作
- **发布日期**：2026-06-09
- **稿件类型**：type-1 品宣活动（品牌合作官宣）
- **对标场景**：光粒与头部媒体/赛事IP达成合作时的官宣稿

### 结构拆解

```
标题：品牌名 + 合作方（央视） + 合作性质（独家合作）

01 事件本身（品类卡位）
  - 开篇一句话定调："AI眼镜首次登陆全球顶级体育赛事舞台"
  - 合作事实陈述（谁+谁+做什么）
  - 历史锚点拉格局："1954年电视第一次转播世界杯" → 类比到当下

02 意义拔高（品牌背书）
  - 国家平台 × 行业先锋 的叙事
  - 品牌成就罗列（全球首个XX、销量第一、多个首创功能）
  - 双方合作的官方口径

03 具体玩法（场景落地）
  - 球迷佩戴AI眼镜的世界杯场景：赛程查询、比分预测、翻译、导航、拍照
  - 线下观赛全场景串联
  - 品牌愿景收束
```

### 可借鉴点

1. **历史锚点开头**：用一个公认的历史节点（1954年电视首次转播世界杯）做类比，把自家事件放进"科技变迁大叙事"里，格局感立刻拉起来。光粒写大合作官宣时可以借鉴这个手法
2. **标题带权威合作方**：标题直接放"中央广播电视总台"而非简称"央视"，正式感和权威感更强
3. **第三段的场景化功能表达**：没有罗列参数，而是用"去现场看球"这个完整场景串联导航→翻译→拍照，功能变成了体验故事。这部分是全文写得最好的，值得学习
4. **"首次"叙事占位**：反复强调"AI眼镜品类第一次进世界杯"，把品牌和品类绑定，让读者形成"Rokid = AI眼镜"的认知

### 需规避点

1. **官腔过重**：大量使用"里程碑""强强联合""驶向更广阔的未来""科技风采"等官方套话，读起来像新闻通稿。光粒品宣稿要求"故事先行"，应避免这种堆砌
2. **信息密度低**：前两部分占2/3篇幅，核心信息只有一句"Rokid成为央视世界杯AI眼镜合作伙伴"，其余都在重复拔高。光粒公众号700-800字的篇幅更要惜字如金
3. **重复表达**："全球领先""全球首个""全球顶级"在全文出现超过10次，形成审美疲劳。同义词重复是品宣稿常见病，写完后应做去重检查
4. **产品功能和品牌成就混在一起**：中间夹杂了"全球首个AI眼镜导航""首个AI眼镜支付""智能体商店"等功能罗列，破坏了叙事节奏。光粒写作原则要求"产品克制，只提核心1-2点"
5. **受众错位**：这篇本质上写给行业/投资人/媒体看的，不是写给消费者的。如果光粒在小红书做品宣，不能用这种调性

### 原文摘要

> AI眼镜首次登陆全球顶级体育赛事舞台。乐奇Rokid与中央广播电视总台正式达成AI眼镜领域独家合作，成为中央广播电视总台2026年美加墨世界杯官方转播合作伙伴。
>
> 1954年，电视第一次转播世界杯，足球赛第一次走进全球普通人的客厅，中国观众在转播画面里看到的大多数是海外品牌。72年后的今天，走进世界杯的是一群中国人自己研发、自己生产的AI眼镜。
>
> 世界杯期间，球迷佩戴乐奇AI眼镜，即可获得赛程查询、技术统计、队伍阵容、球员信息、比分预测、看球辅助等丰富内容和服务。AI导航精准规划路线、实时指引路况，轻松奔赴赛事现场；支持多国语言实时对话翻译，和外国球迷无障碍畅聊；可一键高清拍照、录像，以专属第一视角实时捕捉进球绝杀、精彩扑救等赛场高光时刻。
