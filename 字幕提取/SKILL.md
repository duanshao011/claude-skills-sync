# 字幕提取

把视频链接变成纯文字。**优先原生字幕（免费、准、快），没有字幕再走听悟 ASR。**

## 工具与环境

- `yt-dlp`：抓字幕 + 下载视频（命令行，已装）
- `ffmpeg` / `ffprobe`：音视频处理（已装）
- `scripts/transcribe.mjs`：听悟 ASR 转写（阿里云听悟，配置固定在准星 `app/.env`，**不要动那份 .env**）
- 输出目录：`D:\字幕提取\`（不存在则创建；同名文件覆盖更新）

## 流程

### 第 1 步：判断输入

用户给的是链接还是本地文件；判断平台。链接必须无空格，先 `yt-dlp --version` 确认可调用，不可用告知博哥。

### 第 2 步：先抓原生字幕（默认优先）

```
yt-dlp --write-subs --skip-download --sub-langs "zh.*,zh-Hans.*,en.*" -o "D:\字幕提取\%(title)s.%(ext)s" "<链接>"
```

- 在 `D:\字幕提取\` 下找到 `.srt` 或 `.vtt` 文件 → 走第 3 步
- 没有抓到（报 ERROR 或提示无字幕）→ 走第 4 步
- YouTube 提示网络/需代理（`ProxyError`）时：告诉博哥需要科学上网，不要反复重试

### 第 3 步：字幕转纯文字

读 `.srt` / `.vtt`，规则：
- 删除时间戳行（`00:00:00,000 --> ...` / `HH:MM:SS.mmm`）
- vtt 删除带 `<c>`、`</c>` 等 HTML 标签；srt 删除序号行
- 多行同期字幕合并成一行，中间无空格粘连的合并；压缩空行
- 直接交付文字 + 说明「原生字幕」

### 第 4 步：没有字幕 → 听悟 ASR 转写

```
yt-dlp -f "bv*+ba/b" -o "D:\字幕提取\<标题>.mp4" "<链接>"
```

- 下载失败时（某些平台直链限制）如实告知博哥，不要假装成功
- 视频超过 30 分钟先问博哥是否继续（听悟按分钟计费）
- 再执行：`node "<skill 目录>\scripts\transcribe.mjs" "<视频文件>"`（stderr 是进度，stdout 是文字）
- 脚本输出文字 → 直接交付 + 说明「ASR 转写」；转写失败把脚本 stderr 给博哥看
- 完成后删除临时视频文件（视频太大、占空间，询问博哥是否保留；默认删除）

### 输出规范

- 交付格式：**文字正文** + 一行来源标注（原生字幕 / ASR 转写）+ 视频标题
- 同时保存 `D:\字幕提取\<标题>.txt`（标题含非法字符时用日期时间戳）
- 不许编造视频内容；转写没出来就是没出来，如实说

## 边界

- 密钥、token 不写进对话和文件（听悟配置由脚本自己读）
- 一次只处理一个链接；批量要博哥明确说
- 抖音/小红书视频直链下载失败属正常，提示换 B站/YouTube 源或让博哥用本地文件
